用 MarkCraft 写博客

发布于 2026-08-09 · 阅读 1.2k · 双主题 · 设计

MarkCraft 把本地优先的 Markdown 写作与博客发布打通：编辑、自定义 CSS、主题一键导出，全程不离开桌面。

下面是一段代码示例，展示如何注入主题 token：

:root {
  --blog-accent: var(--mc-accent);
  --blog-bg: var(--mc-bg-app);
}
