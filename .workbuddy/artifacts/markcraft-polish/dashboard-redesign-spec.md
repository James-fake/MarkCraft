# MarkCraft 仪表盘（成长反馈）· 重新设计方案

> 文档性质：设计策略规格（Design Strategy Spec），**非代码实现**。
> 目标：摆脱"企业后台管理系统"式的正式感、密集表格感与彩色图标墙，转向**冷静、高级、有创意的个人成长仪表盘**。
> 设计系统基底：沿用已建立的 `--mc-*` token 体系（accent 蓝 `#5B7CFA`、暗色优先、Inter 字体），保证与产品其余界面 1:1 一致。
> 适用画布：`713265646855574`（MarkCraft 仪表盘重设计）

---

## 0. 调研摘要：2026 年仪表盘设计在往哪走

| 趋势（来源） | 对 MarkCraft 仪表盘的启示 |
|---|---|
| **Bento Grid 成为默认布局**（Apple / Awwwards / orbix.studio） | 用"非对称模块化瓦片"替代等宽卡片墙；瓦片大小即视觉层级，大块=重要数据 |
| **Dark-first 成为标准**（spunk / mediaplus / dev.to） | 暗色为默认体验，近黑而非纯黑（`#0E0F17` 而非 `#000`），语义 token 驱动明暗切换 |
| **"彩色图标墙已死"**（dev.to thekitbase） | 只保留**单一 accent**（蓝 `#5B7CFA`），颜色仅用于状态（绿=健康、琥珀=提醒、红=中断） |
| **Minimal chrome, maximum data**（dev.to） | 边框代替投影、padding 16 而非 24、数字用等宽/tabular、圆角收敛到 8–10 |
| **Glassmorphism 演进为"选择性透明"**（LinkedIn / mediaplus） | 玻璃只用于浮层/导航/侧栏，阅读面保持实体，1px 边框托底 |
| **Micro-interactions 是基线预期**（spunk / vinova） | hover 上浮、数字 count-up、图表 draw-in、尊重 `prefers-reduced-motion` |
| **Interactive charts > 静态图**（dev.to） | sparkline、面积图入场动画、hover tooltip、可点击数据点 |
| **Overview 内嵌实时活动流**（dev.to / peterdraw） | 聚合指标旁放"最近动态"，而非只有月度合计 |
| **Organic / Anti-grid / 流动渐变**（myweb / vinova） | 用柔和的 accent 径向辉光做焦点，打破矩形死板 |
| **个人仪表盘的"冷静感"**（Notion Life OS / Calm Dashboard） | 暖而克制的留白、像"安静的角落"而非工具；这正契合 MarkCraft 的个人知识场景 |
| **Kinetic / 超大数字排版**（muz.li / LinkedIn） | 主指标用超大粗体数字，weight 拉开层级，而非靠框与分隔线 |

**核心结论**：不是"再加装饰"，而是**减少装饰、强化层级、让数据自己说话**。MarkCraft 仪表盘是**个人写作成长反馈**，不是企业 KPI 看板——所以方向应是「冷静高级的个人成长台」，而非「商务数据墙」。

## 1. 设计风格定位

**一句话定位**：*Calm Premium Bento* —— 暗色优先、克制留白、单一强调色、用"空间重量"而非"彩色图标"建立层级，让写作成长像一座安静运转的个人天文台。

| 维度 | 旧（企业后台感） | 新（冷静高级个人台） |
|---|---|---|
| 整体气质 | 密集、表格化、功能堆砌 | 呼吸感、模块化、像私人工作台 |
| 色彩使用 | 多彩图标墙（蓝/绿/橙/紫各一） | 单一 accent + 状态色，其余皆中性灰阶 |
| 层级手段 | 等宽卡片 + 彩色图标 | 瓦片非对称尺寸（Bento）+ 超大数字 |
| 焦点 | 均匀铺开，无主次 | 一块 Hero 主指标锚定视线 |
| 动效 | 几乎无 | 微交互常态化（hover/入场/count-up） |
| 背景 | 平涂 | 极淡 accent 径向辉光做焦点（零素材） |

**关键词**：dark-first · Bento · 单 accent · 克制 · 呼吸感 · 微交互 · 数据自述。

## 2. 色彩与排版方案

### 2.1 色彩（复用 `--mc-*` token，无新增色）

| 角色 | Token | 暗色值 | 用途 |
|---|---|---|---|
| App 背景 | `--mc-bg-app` | `#0E0F17` | 画布底（近黑，非纯黑） |
| 面板/卡片 | `--mc-surface` | `#1A1C24` | 瓦片底 |
| 次级面 | `--mc-panel` | `#14161F` | 侧栏/顶栏 |
| 边框 | `--mc-border` | `#292E30` | 1px 描边（暗态用边框代替投影） |
| 文本 1 | `--mc-text-1` | `#E6E8EF` | 标题/主数字 |
| 文本 2 | `--mc-text-2` | `#8A8F9C` | 标签/说明 |
| **强调** | `--mc-accent` | `#5B7CFA` | **全页仅一处点睛**：Hero 数字、关键图标、活跃态 |
| 成功/健康 | `--mc-success` | `#1FA45C` | 连续写作达标、健康度 |
| 提醒 | `--mc-warning` | `#E0A23B` | 弱提醒（如断更预警） |
| 中断/错误 | `--mc-danger` | `#E5564B` | 同步失败等 |

> **关键纪律**：accent 蓝全页出现≤2 处（Hero 主指标 + 一个激活态/图标点缀）；状态色只承载"好/警/坏"，绝不用于装饰。彻底废除旧稿的"每个卡片一种彩色图标"。

### 2.2 排版（Inter 家族，变量字重建立层级）

| 元素 | 字号 | 字重 | 说明 |
|---|---|---|---|
| Hero 主数字 | 56–64px | 700 | tabular-nums，超大数字即主角 |
| 区块标题 | 15px | 600 | 区块左上角，muted 色 |
| 卡片主数 | 28px | 600 | tabular-nums |
| 正文/标签 | 13px | 400 | text-2 色 |
| 胶囊/小标 | 12px | 500 | letter-spacing 0.04em，uppercase 感 |
| 数字字体 | Inter + `font-variant-numeric: tabular-nums` | — | 所有 KPI 数字等宽对齐，扫描更快 |

**排版纪律**：标题与正文靠**字重+字号**拉开（而非靠框线/底色块）；数字一律 tabular 等宽，纵向一排扫读不串行。

## 3. 核心组件布局建议（Bento，12 列栅格）

> 容器：1440×900 桌面（MarkCraft 为桌面软件，桌面优先）。栅格 12 列，gap 16px，外边距 24px。瓦片用 `grid-column/row span` 表达非对称层级。**暗色为默认**。

### 3.1 信息架构

```
仪表盘（顶栏 56 + 内容区）
├─ 顶栏（玻璃/实体，56px）
│   ├─ 左：Logo + 「成长」标题 + 时间范围切换（本月/本季/本年 分段）
│   └─ 右：主题切换 + 「写今天的笔记 →」主按钮（accent）
├─ Bento 主区（2 行错落）
│   ├─ Hero 瓦片（跨 6 列 × 2 行）★主指标
│   │   ├─ 超大「连续写作」天数 + 火焰图标
│   │   ├─ 本月字数 / 本月笔记数 两个子数
│   │   └─ 背后 accent 径向辉光
│   ├─ 写作热力图（跨 6 列 × 1 行）
│   │   └─ GitHub 式贡献格（53 周 × 7 天），accent 深浅表强度
│   ├─ 月度趋势（跨 6 列 × 1 行）
│   │   └─ 面积 sparkline + hover tooltip（写作字数/周）
│   ├─ 双链网络（跨 4 列 × 1 行）
│   │   └─ 节点数 + 关系数 + 迷你图谱缩略
│   ├─ 标签分布（跨 4 列 × 1 行）
│   │   └─ Top 标签横向条 + 占比
│   ├─ 知识健康度（跨 4 列 × 1 行）
│   │   └─ 圆环进度（如 82%）+ 一句解读
│   └─ 最近动态（跨 12 列 × 1 行）★活动流
│       └─ 时间线：新建/编辑/双链/导入，图标 + 文案 + 相对时间
└─ 底栏（可选）：导出报告 / 设置密度
```

### 3.2 各瓦片视觉规范

| 瓦片 | 尺寸(列×行) | 内容 | 视觉要点 |
|---|---|---|---|
| **Hero 连续写作** | 6×2 | 超大天数 + 火焰 + 本月字数/笔记 | 全页唯一 accent 实心元素；背后 accent 18% 径向辉光；数字 56px 700 tabular |
| **写作热力图** | 6×1 | 贡献格矩阵 | 格 11px 圆角 2，accent 5 级透明度；hover 出日期+字数 tooltip；左侧周几、底部月份刻度（muted） |
| **月度趋势** | 6×1 | 面积 sparkline | 单色 accent 描边 + 10% 渐隐填充；入场从左到右 draw-in；hover 点高亮 |
| **双链网络** | 4×1 | 节点/关系数 + 缩略图谱 | 用现有知识图谱的简化点线缩略；accent 点 + 灰线 |
| **标签分布** | 4×1 | Top5 标签横条 | 横条用 text-2 底 + accent 填充条；右侧占比%；无彩色标签 |
| **知识健康度** | 4×1 | 圆环 82% | SVG 圆环 accent 弧 + 中心数字；下方一句 AI/本地解读文案（muted） |
| **最近动态** | 12×1 | 活动流时间线 | 每行：状态图标（accent/灰）+ 文案 + 相对时间（muted）；最多 5 条，可"查看全部" |

### 3.3 布局自检（对照 web-app 准则）
- **Dominant Region**：Hero 连续写作瓦片（跨 6×2）锚定视线 ✅
- **Single accent**：仅 Hero + 一处激活态用蓝，其余中性 ✅
- **呼吸感**：gap 16、外边距 24、瓦片内 padding 16–20，告别密集表格 ✅
- **Progressive disclosure**：健康度详细解读、动态"查看全部"按需展开 ✅
- **Status states**：空态（无笔记时显示"写下第一篇"引导）、加载（骨架瓦片）、错误（同步失败红点）✅

## 4. 提升质感与创意的具体设计策略

### 策略 A · 用"空间重量"代替"彩色图标"
旧稿用 6–8 个彩色图标平分注意力。新稿：所有瓦片用同一套中性图标（1.5px `currentColor`，text-2 色），**accent 只在 Hero 与激活态出现一次**。眼睛第一眼落在 Hero 大数字，而非被彩色图标牵着走。

### 策略 B · Hero 数字做"主角"
主指标"连续写作 X 天"用 56–64px 700 字重 + tabular 数字。这是整页的视觉锚。配一个火焰图标（accent 实心）。背后叠一层 accent 径向辉光（600px / 18% 不透明），**纯 CSS 零素材**，制造焦点而不喧宾夺主。

### 策略 C · 写作热力图作为"签名元素"
GitHub 贡献格是personal-productivity 最具辨识度的创意元素，且天然契合"成长反馈"。53×7 格、accent 5 级透明度表达强度，hover 出具体日期与字数。它既是数据也是装饰，一举两得，且避开了"企业感"。

### 策略 D · 图表"活起来"
所有趋势/sparkline 用单色 accent，入场从左到右 draw-in（400–600ms），hover 点高亮 + tooltip。废弃静态截图式图表。

### 策略 E · 选择性玻璃 + 1px 边框
顶栏/浮层用 backdrop-blur 玻璃（accent 辉光场景），瓦片阅读面保持实体 `#1A1C24` + 1px `#292E30` 边框——暗态下投影不可见，边框才是层级的正确表达。

### 策略 F · 微交互常态化（尊重 reduced-motion）
- 瓦片 hover：translateY(-2px) + 边框提亮
- 数字：count-up 入场（300ms）
- 图表：draw-in
- 主按钮：active 微缩
- 所有动效 < 300ms（反馈类）/ 400–600ms（布局类），`prefers-reduced-motion` 全关

### 策略 G · 用留白与字重，不用框线
区块标题靠 15px/600 + muted 色，不用底色块；数字靠字重拉开层级，不用分隔线切割。整体"少即是多"，呼应 Notion Life OS 的冷静感。

### 策略 H · 明暗双主题一致
同一套 token，亮色下 app `#F7F8FA`、surface `#FFFFFF`、边框 `#E2E4EC`、accent 不变 `#5B7CFA`、辉光降为 12%。切换零闪白（flash-free）。

## 5. 创意边界（画布能力提示）

以下"视觉真值"画布矢量引擎**画不出**，属实现环节落地（已在 HTML 原型范式验证过）：
- accent 径向辉光、玻璃模糊、hover/入场微交互、品牌字体渲染
- 真实 SVG 面积图 draw-in、热力图 hover tooltip、圆环动画

画布上呈现的是**结构骨架 + token 色板 + Bento 层级**，作为开发参考基线；真实观感以 React+Tailwind 实现时按本方案 + 既有 HTML 原型落地。
