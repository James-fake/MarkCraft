# MarkCraft 日记界面重构方案（Diary Redesign Spec）

> 调研驱动 · 非代码交付物
> 配套画布主板：`713037613352052` 中现有日记帧 `5:97`（MarkCraft · 日记，x:4500）
> 设计语言延续：桌面壳 chrome（标题栏 `5:98` + 侧边栏 `5:104`）+ Calm Premium 暗色 token 体系

---

## 0. 现状诊断（为什么"简陋"）

当前 `5:97` 内容区（1200×866）由两块纯面板拼成：

- **左 `5:109` 月历面板（400 宽）**：只有一个裸月历，无任何"写过/没写"的状态暗示，日历像一张静态表格 → 缺少动力与记忆感。
- **右 `5:167` 当日笔记面板（800 宽）**：标题 `2026-08-09 周五` + 5 行纯文本（`## 今日复盘`、两条正文、一条 `- [ ]`、一条 `- [x]`）。没有层级、没有上下文、没有引导，像一份没排版的 txt。

**核心问题**：信息密度低、视觉层级平、缺少"写作仪式感"与"记忆温度"，与已重设计的仪表盘（Calm Premium Bento）风格割裂。

| **Diarium / Journey** | 热力图连续性视图、心情+天气标签、日历游戏化 | 一致性热力图；天气/地点自动标签 |

## 2. 设计风格定位

**名称：`静谧手记 / Calm Sanctuary`**

- **调性**：calm · focused · warm-but-restrained · private
- **与现有体系关系**：沿用仪表盘已建立的 Calm Premium 暗色 token（accent `#5B7CFA`、surface `#1A1C24`、border `#292E30`、text `#E6E8EF`/`#8A8F9C`），不再引入新主色，保证整本设计稿统一。
- **差异化**：仪表盘是"数据 Bento"，日记是"书写仪式"——用**更大留白、衬线日期 accent、柔和渐变语境条、连续性反馈**拉开情绪，而非另一种数据面板。

---

## 3. 设计原则（5 条）

1. **聚焦书写**：进入即写，最多两次点击开始；工具栏/元信息不抢视线。
2. **连续性即奖励**：日历点状 + streak + 迷你热力图，把"坚持"可视化（游戏化但不幼稚）。
3. **记忆有温度**：自动元数据（日期/星期/天气/地点）+ On This Day 闪回，让每篇日记自带情境。
4. **克制的心情信号**：一键心情用柔和点/细线，而非 emoji 马戏团。
5. **层级靠排版不靠框线**：衬线大日期 + 舒适行高 + 受限字宽（measure），营造"纸感"。

---

## 4. 色彩与排版方案

### 4.1 色彩（复用 Calm Premium token，新增 2 个语义轻量）

| 角色 | 值 | 用途 |
|---|---|---|
| 背景（最底） | `#0E0F17` | 内容区底 |
| 表面卡 | `#1A1C24` | 月历/条目/语境条容器 |
| 表面-纸（编辑区） | `#16181F`（比表面略冷一档） | 编辑"纸面"，与周围区分 |
| 描边 | `#292E30` | 所有卡片描边 |
| 主文字 | `#E6E8EF` | 标题/正文 |
| 次文字 | `#8A8F9C` | 标签/元信息 |
| **Accent** | `#5B7CFA` | 今日环、连续数、CTA、心情选中 |
| 成功/已写 | `#1FA45C` | 日历"已写"点、完成任务 |
| 暖强调（新增·轻） | `#E8C39E`（低饱和暖米） | 衬线日期 accent、On This Day 引文，给冷调一点温度 |
| 心情刻度 | accent 5 级透明度 | 心情 chip 填充 |

> 对比度均满足 WCAG AA（主文字 `#E6E8EF` on `#1A1C24` 约 13:1；次文字 `#8A8F9C` on `#1A1C24` 约 4.6:1）。

### 4.2 排版（温度 + 结构 配对）

- **Display / 大日期数字 / 条目标题**：衬线体（如 `Fraunces` / `Newsreader` / 系统 `Songti SC` 中文回退），字重 500–600，营造"手记"温度。
- **UI / 正文 / 元信息**：`Inter`（已落地），中文回退 `PingFang SC` / `微软雅黑`。
- **字号梯度**：大日期 44–56px / 条目标题 20px / 正文 16px（行高 1.7）/ 元信息 12–13px。
- **编辑区 measure**：正文最大宽度 ~680px，避免长行疲劳。

## 5. 组件结构与布局（替换内容区 `5:108`）

> 内容区 1200×866，保留左右分栏但重塑。建议分栏：**月历/连续性面板 380 宽 + 16 间距 + 当日书写面板 804 宽**。

### 5.1 左面板：月历 + 连续性（380 × 866）

```
┌─ 月历与连续性 ────────────────┐
│  ←  2026 年 8 月       今天  │   ← 表头：月份 + 前后翻 + 今天跳转
│  一 二 三 四 五 六 日        │
│  [ ][●][ ][ ][●][ ][ ]      │   ← 日期格：●=已写(accent/success)，
│  [●][ ][ ][●][ ][ ][●]      │      今日加 accent 圆环
│  ... (6 行)                  │
│ ┌─ 连续写作 ──────────────┐  │
│ │ 🔥 47 天   本月已写 18 天 │  │   ← streak 迷你卡（复用仪表盘 Hero 语言）
│ └────────────────────────┘  │
│ ┌─ 写作热力（迷你）───────┐  │
│ │ ▓░▓░▓░ ... 12 采样格     │  │   ← 一致性热力图（accent 多透明度）
│ └────────────────────────┘  │
│ ┌─ 那年今日 ──────────────┐  │
│ │ "2025-08-10：第一次…"   │  │   ← On This Day 闪回（暖强调引文）
│ └────────────────────────┘  │
└──────────────────────────────┘
```

**交互**：日期格 hover → 浮层预览该日首行；点击 → 切到该日条目；已写日点 success/accent，今日环 accent。

### 5.2 右面板：当日书写（804 × 866）

```
┌─ 当日书写 ───────────────────────────────────────┐
│ 8月10日          周一                              │   ← 语境条
│ 10              （衬线大数字 accent 暖调）          │
│ [平静][愉快][疲惫][兴奋][低落]   ☁ 26° 北京 · 已自动保存│ ← 一键心情 + 天气/地点标签
│ ───────────────────────────────────────────────  │
│ 今天有什么值得记录的？(淡灰斜体提示，聚焦即隐)       │   ← 引导 prompt，消除空白页焦虑
│                                                    │
│ ## 今日复盘                                        │   ← 编辑区（纸面 #16181F）
│ 完成了日记界面的重构方案…                          │      行高 1.7 / measure 680
│ - [x] 提交周报    - [ ] 整理组件库                 │      任务清单样式化（✓ 用 success）
│ （可滚动，舒适留白）                               │
│                                                    │
│ ───────────────────────────────────────────────  │
│ 328 字   自动保存于 12:04   ⊕ 附件  ⤴ 分享为卡片   │   ← 底栏：字数/状态/快捷操作
└────────────────────────────────────────────────────┘
```

**关键组件说明**

| 组件 | 说明 |
|---|---|
| 语境条（Context Bar） | 衬线大日期 + 星期 + 一键心情 chip + 天气/地点自动标签 + 自动保存态。给每篇日记"时间坐标"。 |
| 心情 chip | 5 态柔和点，选中填 accent 低透明，文字标签次色；克制无 emoji 堆砌。 |
| 引导 prompt | 淡灰斜体一行，编辑区聚焦后淡出；对应 Grid Diary / Day One 模板消除空白页焦虑。 |
| 编辑纸面 | 受限字宽、行高 1.7、标题层级清晰、任务清单 `✓` 用 success 色，呈现"纸感"而非裸文本。 |
| 底栏 | 字数统计 + 自动保存指示 + 附件/分享为卡片快捷操作（呼应 dailynote "share as card"）。 |
| On This Day 闪回 | 左面板底部暖强调引文卡，点击展开往年同日条目（Day One 最受喜爱功能）。 |

## 6. 核心视觉元素清单

1. 衬线大日期数字（温度锚点）
2. 日历点状连续性 + 今日 accent 圆环
3. streak 迷你卡（连续写作天数）
4. 迷你写作热力图（一致性反馈）
5. 一键心情 chip（克制信号）
6. 自动元数据标签（天气/地点/时间）
7. On This Day 闪回卡（记忆温度）
8. 引导 prompt（消除空白页焦虑）
9. 受限字宽编辑纸面 + 样式化任务清单
10. 底栏字数/自动保存/分享卡片

## 7. 改进要点对照（现状 → 重构）

| 维度 | 现状（简陋） | 重构后 |
|---|---|---|
| 月历 | 静态表格，无状态 | 点状连续性 + 今日环 + hover 预览 + streak + 热力图 |
| 书写区 | 5 行裸文本 | 语境条 + 引导 + 纸感编辑 + 底栏 |
| 视觉层级 | 全平 | 衬线日期 accent + 卡片分区 + 柔阴影 |
| 情感连接 | 无 | On This Day + 自动元数据 + 心情 |
| 写作动力 | 无 | 连续性游戏化 + 引导 prompt |
| 风格统一 | 与仪表盘割裂 | 同 Calm Premium token，情绪差异化 |
| 排版 | 单无衬线平铺 | 衬线 display + 无衬线 body，行高 1.7，measure 受限 |

## 8. 交互与微交互（实现层建议）

- **进入即写**：打开日记默认焦点在编辑区，prompt 淡出。
- **日历连续性**：已写日点 success；悬停 preview 浮层；点击切换日。
- **心情一键**：选中即填 accent 低透明，配次色文字。
- **On This Day**：左面板卡点击展开侧滑往年条目。
- **自动保存**：底栏"已自动保存于 HH:MM"脉冲淡入。
- **分享卡片**：底栏将当日条目渲染为设计卡（dailynote 式），可导出 PNG。
- **尊重 reduced-motion**：上述动画在 `prefers-reduced-motion` 下降级为即时切换。

---

## 9. 可访问性（WCAG AA）

- 正文/次文字对比度 ≥ 4.5:1（已核算）。
- 心情 chip、日历格均为 ≥ 44×44 触控/点击目标。
- 键盘可达：日历方向键导航、Tab 走心情 chip、Enter 写当日。
- 焦点环统一 accent 2px offset 2px。
- 日期/星期用 `aria-label` 而非仅视觉。

## 10. 落地建议（下一步选项）

- **A｜同步到画布**：按本方案替换主板 `5:97` 内容区（保留标题栏/侧边栏 chrome），输出结构对齐板（画布无法画真实辉光/渐变/动画，属实现层）。
- **B｜HTML 高保真原型**：写实衬线字体、柔和渐变语境条、hover 预览、心情选中态、分享卡片，作为开发视觉真值基线。
- **C｜React 实现规格**：给出 `--mc-*` token 映射 + 组件 props + 状态机，直接进代码。
