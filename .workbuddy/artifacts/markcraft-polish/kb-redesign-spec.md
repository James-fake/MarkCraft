# MarkCraft 知识库界面重构方案 — Calm Knowledge Hub

> 基于联网灵感调研 + 当前 `5:215` 结构诊断，提出的完整界面重构方案。
> 目标：在保持 Calm Premium 设计家族一致性的前提下，把"简陋的文件总览"升级为"有呼吸感、有数据、有层级"的知识中枢。

---

## 一、灵感来源与提炼（联网调研）

| 来源 | 关键可借鉴点 | 映射到本方案 |
|------|------------|------------|
| **Obsidian（OpenDesign 设计系统）** | 深暗底 + 单一高饱和强调色；humanist-sans 标题加粗收紧；8px 间距栅格；4/8/12px 圆角；1px 细边框定义面而不靠重阴影；药丸形 chip；"不要拥挤、要留白与清晰层级" | CalmPremium 暗色令牌 + 单 accent 纪律 + 卡片圆角 + 细边框 |
| **Logseq 设计系统** | 深青底 + 柔和发光强调色；半透明玻璃卡片；克制、沉浸式、留白充足 | 用 accent 低透明发光点（图谱预览）营造"活的知识"感 |
| **Heptabase** | "视觉 memex"：白板 + 笔记 + 双链 + 标签的可视化混合；知识像摊开在桌上 | 知识图谱预览卡 → 与 Neural Atlas 屏联动 |
| **Tolaria / Blinko / MarKing（现代四栏 PKM）** | 类型即导航（类型带颜色+图标）；键盘优先；命令面板覆盖一切；右侧栏=属性/反链/目录 | 文件夹树加类型图标+计数；顶部"新建笔记"CTA（捕捉优先） |
| **PKM 构建原则（Koder.ai）** | 捕捉优先（打开→捕捉→继续）；导航要简单、搜索不能藏；空状态是体验一部分；最小可预测元数据（标题/时间/标签/链接/收藏/状态） | 顶部视图切换 + 常驻新建；活动流替代空旷 |
| **知识图谱可视化** | 自动社区聚簇、力导向、本地优先；节点按类型/社区着色 | 图谱预览用 accent / 语义色区分节点类型 |

**提炼出的三条设计支柱**：
1. **单一强调色纪律**（CalmPremium `accent` #5B7CFA 贯穿，不引入竞争色）
2. **慷慨留白 + 清晰层级**（标题栏 → 操作条 → 统计带 → 内容网格，信息有主有次）
3. **让知识"活"起来**（健康分、活动流、图谱预览，而非静态文件列表）

---

## 二、设计风格定位

**Calm Knowledge Hub（沉静知识中枢）**
- 调性：聚焦、冷静、专业，像 Obsidian 的纪律 + Logseq 的沉静 + Heptabase 的视觉化。
- 与已完成的 9 屏保持同一套 CalmPremium 令牌（Dark/Light 双模式自动适配）。
- 不追求玻璃模糊/辉光等画布无法实现的效果，改用**细边框 + 单 accent + 留白 + 类型色**达成高级感。

---

## 三、核心视觉元素

1. **顶部操作条**：面包屑（工作区 / 项目A）+ 视图切换（总览 · 文件夹 · 图谱）+ 常驻「＋ 新建笔记」accent 主按钮（捕捉优先）。
2. **统计卡片带（4 块）**：笔记总数 / 双链数 / 待复习 / 知识健康分。每块含图标 + 大数字 + 次级标签 + 变化指示（accent 或语义色）。
3. **优化文件夹树**：分区标题 + 类型图标 + 条目计数徽标 + 激活态高亮（bg-elevated + accent 左条）。
4. **语义搜索升级**：顶部通栏 + 筛选 chip（全部/标题/标签/内容）+ "本地统计"语义标注保留。
5. **最近活动流**：时间线列表（时间 + 类型 chip + 标题），替代原大片留白。
6. **待复习 / 任务卡**：加图标 + 进度/勾选语义色（success/warning/danger）。
7. **知识图谱预览卡**：mini 节点簇（SVG，accent/语义色区分类型），呼应 Neural Atlas。

## 六、令牌与一致性

全部新增元素必须引用 `CalmPremium` 变量（`$:CalmPremium:bg-panel` 等），确保 Dark/Light 切换自动统一。
- 主按钮/选中/图标强调 → `accent`
- 待复习/警示 → `semantic-warning`
- 健康分/完成 → `semantic-success`
- 危险/删除 → `semantic-danger`
- 文字三级 → `text-primary` / `text-secondary` / `text-tertiary`
- 卡片面 → `bg-panel`；浮起面 → `bg-elevated`；分隔 → `border-subtle`
- 圆角 → 卡片 12px、chip/按钮 pill、输入框 8px（与现有令牌一致）

## 七、落地建议

- **画布实现（5:215）**：按上方节点树增删/重排节点，全部绑 CalmPremium。受画布限制，图谱预览用静态 SVG 节点簇（非实时力导向），辉光用低透明 accent 圆点近似。
- **真值原型（推荐）**：先出 HTML 高保真样机（见同目录 `kb-redesign-mockup.html`）验证双模式与视觉，再回流到画布。
