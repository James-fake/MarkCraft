## 0. 现状诊断（为什么"简陋"）

当前 `5:1` 的内容区是「图谱画布 980 + 节点详情 220 + 底部工具条 28」三段式，问题集中在**图谱画布本身**：

| 问题 | 表现 | 后果 |
|---|---|---|
| 节点无身份 | 6 个纯色圆，标签（项目计划/读书笔记…）是画布上**游离的文本**，不贴节点 | 看不出"谁是谁"，无层级 |
| 无类型区分 | 所有节点同形状同大小，仅靠填充色微差 | 笔记 / 标签 / 文件夹混为一谈 |
| 连线无意义 | 5 条细灰线（`#26292F`），无方向、无权重、无高亮 | 关系网读不出结构 |
| 详情面板空洞 | `5:26` 220 宽但无内容骨架 | 右侧空间浪费，点击无反馈预期 |
| 工具条徒有其表 | `5:35` 28px 薄条，无缩放/筛选/搜索/图例 | 无导航、无控制感 |
| 无状态 | 无图例、无统计、无空态 | 大图下迷失，小库下空白 |

**根因**：把"知识图谱"当成了"几个圆圈 + 几根线"的示意图，而非一个**可探索的知识主舞台**。

## 1. 调研提炼（6 类标杆案例）

1. **Framer · Orbit Node Graph**（premium 组件）
   - Smart Anti-Collision 引擎自动避让；10+ 主题（Cyber / Midnight / Glass / Emerald / Linear）
   - 氛围辉光背景、连线内浮动粒子、hover 时**淡化无关节点**聚焦当前
   - 移动端从放射图自动转为纵向时间线；零配置 Lucide 图标

2. **Neo4j Aura + PyVis 设计思维**
   - 色彩心理学：核心节点放大 15%、边框粗细区分重要性（2px vs 1px）
   - 文字对比 ≥4.5:1（WCAG）；高亮态用互补色
   - 物理引擎：Barnes-Hut 聚拢、springLength 控边距、avoidOverlap 防遮挡

3. **Lore Web（D3 力导向）**
   - 按类型/置信度/标签过滤节点；边高亮关系；**minimap 导航**；虚拟化处理千级节点
   - 暗色 + 青色 accent；动效克制、目的明确

4. **Obsidian（OpenDesign 拆解）**
   - 单一高饱和 accent（紫 `#8A5CF5`）、高对比暗色、humanist-sans + monospace
   - **铁律：不要多个竞争强调色**、不要 0 圆角、不要密集杂乱、sentence case

5. **k8ai/knowledge_graph 前端方案**
   - 定位"研究工作台"而非后台；**主舞台优先**（图谱恒为视觉中心）
   - 信息密度有层次：概览轻 / 详情深 / 编辑聚焦；动效只强化切换·聚焦·路径流动

6. **2026 暗色仪表盘范式（Linear / Vercel / Grafana）**
   - 真灰底（`#0E–#1A`，非纯黑）、背景明度分层做 elevation、单饱和 accent、borderless 卡片、暗色专用字重调校、语义色暗色适配

**可落地的设计语言（提炼）**
- 图谱 = 主舞台，永远占视觉中心且最大权重
- 单 accent 纪律（沿用仪表盘/日记的 `#5B7CFA`，不引入竞争色）
- 节点靠**尺寸 + 边框 + 类型色 + 标签**建立层级
- hover/选中 → 淡化无关、点亮路径（画布画不出，实现层落地）
- 右侧 Insight 面板：节点详情 + 全局统计 + 筛选
- 底部工具条升级为：缩放 / 适应屏幕 / 筛选 chips / 搜索 / 图例 / minimap

## 2. 风格定位

**`神经元星图 / Neural Atlas`** —— 把知识网想象成夜空中的星座：

- 与已重设计的**仪表盘（Calm Premium Bento）**、**日记（Calm Sanctuary）**同源异情绪
- 共用同一套暗色 token（`--mc-*`），但情绪更"探索感"：更大留白、节点如星、连线如光迹
- 单 accent `#5B7CFA` 作为"当前/选中/路径"的信号色；节点类型用低饱和语义色区分（不抢 accent）

## 3. 色彩与排版（复用 Calm Premium token）

### 色彩
| 角色 | 值（暗色） | 用途 |
|---|---|---|
| 背景底 | `#0E0F17` | 画布 |
| 表面（卡/面板） | `#14161F` | 右侧 Insight、底部条 |
| 表面 elevated | `#1A1C24` | hover/弹层 |
| 描边 | `#292E30` | 1px 边框定义表面 |
| 文本主 | `#E6E8EF` | 标题/节点标签 |
| 文本次 | `#8A8F9C` | 说明/坐标轴 |
| **Accent（信号）** | `#5B7CFA` | 选中节点、路径高亮、主操作 |
| 节点类型色（低饱和） | 笔记 `#5B7CFA` / 标签 `#1FA45C` / 文件夹 `#C9A227` / 灵感 `#A06CD5` | 仅用于节点填充，不用于 UI |
| 连线 | `#26292F` 常态 → `#5B7CFA` 高亮 | 关系 |

> WCAG：文本 `#E6E8EF` on `#0E0F17` ≈ 15:1；次文本 `#8A8F9C` ≈ 5.3:1，均过 AA。

### 排版
- 字体：界面 Inter（已用）；节点标签 Inter Medium 12–13px
- 层级：画布标题 15/SemiBold；Insight 区标题 15/SemiBold；KPI 数字 28/Bold；说明 12/Regular
- 字重：暗色专用，标题 Bold、正文 Medium/Regular（避免纯白刺眼）

## 5. 核心组件结构

### 5.1 主舞台 · 图谱画布
| 元素 | 说明 |
|---|---|
| 节点（笔记型） | 圆形/圆角矩形，accent 描边 + 标签贴节点下方；选中时外环 + 辉光 |
| 节点（标签型） | 较小，绿 `#1FA45C` 填充，菱形或胶囊 |
| 节点（文件夹型） | 方形，金 `#C9A227` 描边 |
| 节点（灵感型） | 紫 `#A06CD5` 小点 |
| 连线 | 曲线/直线，常态灰；hover 节点时**相关边 accent 高亮、无关节点降透明度** |
| 顶部浮层 | 玻璃态（实现层）：搜索框 + 类型筛选 chips（笔记/标签/文件夹/灵感）+ 聚类/力导向切换 |
| minimap | 右下悬浮小窗，显示全局缩略 + 当前视口框（千级节点导航） |
| 空态 | 居中插画 + "还没有双链，写第一篇笔记开始编织知识网" + CTA |

### 5.2 右侧 Insight 栏（替代空洞的 节点详情）
| 区块 | 内容 |
|---|---|
| 选中节点卡 | 节点名（大字）+ 类型 chip + 字数/链接数 + "打开笔记"主按钮 |
| 全局统计 | 节点总数 / 关系总数 / 最大连通簇 / 孤立节点数（小数字网格） |
| 类型图例 | 4 类节点色块 + 名称，点击可筛选 |
| 相关双链 | 该节点的前向/后向链接列表（可点击跳转） |

### 5.3 底部工具条（升级）
缩放 − / + 、适应屏幕、实际尺寸、布局（力导向/层级/时间线）、导出 PNG、帮助。图标按钮 + tooltip。

| 维度 | 现状 | 重构后 |
|---|---|---|
| 节点身份 | 游离文本标签 | 标签贴节点，类型色 + 尺寸建层级 |

| 详情 | 220 宽空面板 | Insight 栏：选中卡 + 统计 + 图例 + 双链 |
| 控制 | 薄条无功能 | 缩放/筛选/搜索/minimap/导出 |

| 一致性 | 与全局割裂 | 同源异情绪的 Calm 体系 |

## 7. 交互与动效策略（实现层落地，画布仅标注）

- **聚焦（focus）**：点击/悬停节点 → 该节点及直接邻居保持高亮，其余降透明度至 0.25
- **路径流动**：选中两节点 → 最短路径连线 accent 流动光点
- **入场**：图谱首次渲染，节点从中心向外 spring 展开（非一次性出现）
- **辉光**：当前节点外发光（box-shadow accent 多透明度）
- **连线粒子**：关系线上缓慢浮动的小光点，暗示"连接活性"
- **尊重 reduced-motion**：以上动效在 `prefers-reduced-motion` 下全部关闭

---

## 8. 响应式（层级存活）

- **桌面（≥1024）**：主舞台 + 右侧 Insight 栏（本文档目标）
- **平板（640–1023）**：Insight 栏收为可唤起的右侧 sheet，默认隐藏
- **移动（<640）**：图谱转纵向"时间线/列表"视图（参考 Obsidian / Framer 移动端），节点卡片堆叠，连线退化为缩进层级
