# MarkCraft 首启引导页 · 重新设计方案

> 文档性质：设计规格（Design Spec），非代码实现。
> 目标：以当前已建立的 `--mc-*` 设计系统为基底，参考 2026 年高质量网站首页案例，重做"进入编辑器前的首启引导页"，消除原稿"元素漂浮、无容器、无价值主张、层级混乱"的问题，让信息层级清晰、视觉协调、有设计感。
> 适用画布帧：`9:96`（MarkCraft · 首启引导）

---

## 0. 调研摘要：从优秀案例借什么

| 参考来源 | 可借鉴的模式 | 在 MarkCraft 首启页的落地 |
|---|---|---|
| Linear / Vercel / Raycast（开发者工具主页） | 深色为底、超大自信标题即主角、单一主 CTA、克制用色 | Hero 区 + 唯一主按钮"新建第一篇笔记" |
| Notion 引导流 | 渐进式披露、learn-by-doing、可"跳过"、不堆功能 | 首启不展开全部能力，给"跳过，直接开始"出口 |
| Apple / Linear Bento 网格 | 模块化错落卡片展示能力，信息密集但和谐 | 中部"核心能力"Bento 网格，替代漂浮元素 |
| Stripe / Vercel | 零素材的辉光/聚光效果（径向渐变）制造焦点 | Hero 背后 accent 径向辉光，纯 CSS、不增资源 |
| 2026 趋势（born digital / betwixt / launchpad） | dark-first、glassmorphism/liquid glass、bento、微交互、暗态"用边框代替阴影" | 顶部玻璃条、芯片、卡片边框代替投影、入场微交互 |
| Obsidian | 本地优先、数据自有、信任感 | 底部信任条："100% 本地存储 / 0 云端依赖" |

**核心结论**：首启页不是营销落地页，应"快进快出"——但可以用网站级的设计语言（大字体 Hero、Bento、辉光、玻璃、微交互）把"丑/简陋"彻底去掉，同时保持单一主操作与明确出口。

---

## 1. 设计目标与原则

1. **3 秒说清**：用户一眼明白"这是什么、下一步点哪"。
2. **单一主操作**：主按钮"新建第一篇笔记"一枝独秀，其余降级为次级/文字链。
3. **信息和谐**：用 Bento 容器收拢能力，消除原稿"散落漂浮"。
4. **暗色优先**：accent 蓝 `#5B7CFA` 全页仅一处点睛（主按钮 + 一个关键词 + 图标点缀）。
5. **快进快出**：首启不强制多步，给"跳过"出口；能力靠卡片"看"而非"读长文"。

## 2. 信息架构

```
首启引导（全屏覆盖层，1440×900）
├─ 顶部细导航条（玻璃）
│   ├─ 左：Logo + MarkCraft wordmark
│   └─ 右：主题切换图标按钮 + "跳过，直接开始 →" 文字链
├─ Hero 区（居中）
│   ├─ Kicker 芯片（玻璃 pill）：本地优先 · Markdown · 知识图谱
│   ├─ 主标题（超大，关键词 accent）：Markdown 写作，知识自动成网
│   ├─ 副标题（muted 一行）
│   └─ CTA 组：主按钮「新建第一篇笔记」+ 次级「打开文件夹」「导入笔记」
├─ 核心能力 Bento 网格（2×2 错落）
│   ├─ 卡A 双内核编辑（宽，含迷你编辑器预览）
│   ├─ 卡B 双链图谱
│   ├─ 卡C 白板
│   └─ 卡D 知识库 / 本地语义检索
└─ 底部信任条
    ├─ 100% 本地存储
    ├─ 0 云端依赖
    └─ 双主题 · 跨平台（支持导入 Obsidian / Notion）
```

## 3. 各板块布局说明（基于 1440×900 暗色全屏）

### 3.1 顶部细导航条
- 区域：全宽 1440，高 56，y 0–56。
- 左：Logo 24×24 + `MarkCraft` 文字（16px / 600）。
- 右：主题切换图标按钮（28×28，surface 圆角 8）+ 文字链"跳过，直接开始 →"（13px，muted）。
- 材质：surface 70% 不透明 + 1px border + 背景模糊 12（liquid glass），底部一条 1px 分隔。
- 作用：给明确"出口"，不强迫停留。

### 3.2 Hero 区
- 区域：水平居中，内容宽约 760，y 150–430。
- Kicker 芯片：居中 pill，高 32，`本地优先 · Markdown · 知识图谱`（12px，letter-spacing 0.04em，glass）。
- 主标题：居中，约 52px / 700，两行，其中"成网"用 accent 着色：`Markdown 写作，` / `知识自动成网。`
- 副标题：居中，16px / 400，muted，单行：写作、连接、勾勒，一个工作台全搞定。
- CTA 组：居中，主按钮高 44（accent 实心）+ 其右两个次级文字链"打开文件夹""导入笔记"，间距 20。
- 背后：accent 径向辉光（600px，18% 不透明，居中偏上），零素材。

### 3.3 核心能力 Bento 网格
- 区域：y 470–720，容器内宽约 1080 居中，12 列栅格、列间距 16、行间距 16。
- 错落布局（2×2 非对称）：
  - 卡A 双内核编辑：占 12 列中左 8 列（宽卡），含迷你编辑器预览（左侧源码 / 右侧富文本的小样，示意"一键切换"）。
  - 卡B 双链图谱：占右 4 列（窄卡），含小型节点-连线示意（3 节点 + 2 连线）。
  - 卡C 白板：占左 6 列，含便签/箭头小样。
  - 卡D 知识库 / 本地语义检索：占右 6 列，含搜索 + 标签 chip 小样。
- 每张卡结构：圆形 accent-soft 图标块（32×32，1.5px stroke 几何图标）+ 标题（15px / 600）+ 描述（13px / muted，最多两行）。
- 作用：用容器收拢能力、错落大小制造节奏，解决原稿"漂浮无锚点"。

### 3.4 底部信任条
- 区域：y 750–840，水平居中，三项等距。
- 每项：大数字（28px / 700，accent）+ 下方小标签（13px，muted）。
  - `100% 本地存储` · `0 云端依赖` · `双主题 · 跨平台`
- 右端可选一行小字：`支持导入 Obsidian / Notion`（12px，muted）。
- 作用：本地优先产品的"社会证明"等价物，建立信任。

### 3.5 出口与主题切换
- 两处"跳过"入口：顶部右侧文字链 + 底栏惯性位置，点击直接进入编辑器空状态。
- 主题切换：顶部图标按钮即时切换明/暗（与设置里的主题 token 同源），切换时整页 cross-fade 300ms。

## 4. 视觉风格建议

### 4.1 色彩（与现有 token 对齐，暗色优先）
| 角色 | Token | 暗色值 | 用途 |
|---|---|---|---|
| 页面底 | --mc-bg-app | `#0E0F17` | 全屏背景 |
| 卡片面 | --mc-surface | `#1A1C24` | Bento 卡、顶部条 |
| 面板 | --mc-panel | `#14161F` | 次级容器 |
| 描边 | --mc-border | `#292E30` | 暗态用边框代替投影 |
| 文本1 | --mc-text1 | `#E6E8EF` | 标题、卡标题 |
| 文本2 | --mc-text2 | `#8A8F9C` | 副标题、描述、标签 |
| 强调 | --mc-accent | `#5B7CFA` | 主按钮、关键词、图标点缀 |
| 强调柔底 | --mc-accent-soft | `rgba(91,124,250,0.12)` | 图标块、辉光 |

### 4.2 字体层级
- 主标题：Inter / Geist，700，clamp(40, 5vw, 56)px，letter-spacing -0.02em。
- 副标题：16px / 400，text2。
- Kicker / 标签：12px，letter-spacing 0.04em，大写感。
- 卡标题：15px / 600，text1。
- 卡描述：13px / 400，text2。
- 信任数字：28px / 700，accent。

### 4.3 圆角 / 描边 / 层级（暗态规范）
- 圆角：卡片 12、控件/芯片 8、按钮 8、pill 999。
- 暗态 elevation：**不用投影制造深度**（深色下投影不可见），改用 1px border + hover 时 surface 提亮 1 档；仅主按钮用 accent 辉光（box-shadow accent 24% / 0 0 0）。
- 卡片 hover：translateY(-4px) + border 提亮至 accent-ish + 轻微辉光。

### 4.4 辉光与玻璃（视觉精致感来源）
- Hero 辉光：accent 径向渐变，600px，18% 不透明，居中偏上，纯 CSS 零素材。
- 玻璃：顶部条、Kicker 芯片用 surface 70% + 1px border + backdrop-blur 12（liquid glass）。

### 4.5 留白节奏（4px 基数）
- 区块间距 48–64；卡内 padding 24；卡间距 16；Hero 内部元素间距 16–20。

## 5. 关键界面元素规划

| 元素 | 规格 | 状态与微交互 |
|---|---|---|
| 顶部玻璃条 | surface 70% + blur12 + 1px border | 静态；底部 1px 分隔 |
| Kicker 芯片 | pill，glass，12px | 静态 |
| 主按钮「新建第一篇笔记」 | accent 实心，高 44，圆角 8 | hover 上浮+辉光；active scale .98；focus-visible 2px accent ring offset 2 |
| 次级文字链 | 13px muted | hover 下划线 + 提亮至 text1 |
| Bento 卡（×4） | surface + 1px border，圆角 12 | hover translateY(-4) + border 提亮 + 辉光；整卡可点（进对应模块/示例） |
| 图标块 | accent-soft 圆底 32 + 1.5px stroke 几何图标 | 静态 |
| 信任条数字 | 28px/700 accent | 静态 |
| 主题切换 | 28×28 图标按钮 | 即时切明/暗，整页 cross-fade 300ms |
| 入场动画 | Hero→卡片 stagger fade-up | 尊重 `prefers-reduced-motion` |

## 6. 明暗双主题适配
- 暗色为默认（项目已定 dark-first）。
- 亮色变体：--mc-bg-app `#F7F8FA`、--mc-surface `#FFFFFF`、--mc-panel `#ECEEF3`、--mc-border `#E2E4EC`、--mc-text1 `#1F2129`、--mc-text2 `#5B606B`、accent 不变 `#5B7CFA`。
- 亮色下辉光改为更柔和的 accent 6% 薄雾；玻璃改为 white 70% + 更轻的 border。
- 结构、栅格、圆角、间距双主题完全一致。

---

## 7. 与现有设计系统 token 对齐
- 本方案所有颜色直接映射项目已有的 `--mc-*` token，未引入新色（accent 仍为已定的蓝 `#5B7CFA`，非通用模板紫）。
- 圆角梯度（12/10/8）、描边 `#292E30`、间距 4px 基数，与已精修的全量画布帧一致。
- 组件语言（按钮、卡片、芯片、图标 1.5px stroke）与 P0 壳 / 知识图谱 / 设置原型同源。

## 8. 落地建议（画布 vs 实现）
- **画布（Ardot `9:96`）可承载**：分区结构、Bento 卡片、文字、圆角、1px 描边、accent 着色、图标块——作为"结构对齐板"。
- **画布无法承载**：Hero 辉光、玻璃模糊、hover/入场微交互、品牌字体——这些属"视觉真值"，照本文档 + 后续 HTML 原型在实现环节落地。
- **推荐流程**：① 本文档作为开发参考基线；② 将结构层（分区/Hero/Bento/信任条/退出）同步到 `9:96`；③ 真实观感以 HTML 原型或最终实现为准。
