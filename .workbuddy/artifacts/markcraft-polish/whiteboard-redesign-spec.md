## 0. 联网调研摘要（2026-08-10）

| 来源 | 关键洞察 | 对本设计的启示 |
|---|---|---|
| **tldraw**（45k★ 无限画布 SDK） | 干净几何图形、Figma 式专业观感；暗色 `hsl(240,5%,6.5%)` 背景 + 浅色文字；主题基于 CSS 变量；选择框/描边用半透明 accent | 暗底 + 单一 accent + 边框代投影，正是我们的 Calm Premium 语言；工具条要"精致专业"而非"手绘草图" |
| **Excalidraw**（MarkCraft 实际内核） | 手绘草图风、便签黄、协作链接；零学习曲线；命令面板 + 快捷键 | 保留其实用内核，但**外部 chrome 升级**为高级感；保留命令面板入口 |
| **Miro / FigJam** | 便利贴、形状库、连接器、模板、演示模式、实时协作光标 | 顶部工具组 + 右侧样式/图层面板 + 底部缩放/minimap 是行业事实标准 |
| **draw.io / Whimsical** | 深形状库（UML/BPMN/ERD）、模式化默认（流程图/线框/脑图各自专用模式） | 视图切换（看板/脑图/时间线）应是一等公民，而非一个下拉 |
| **NNGroup · 上下文菜单 10 准则** | 次级操作就近、用 kebab/meatball 图标、分组+分隔线、≤10 项、必须有冗余入口（键盘/主菜单）、选中对象保持可见 | 右键上下文菜单：分组、分隔、复制/删除/层级/锁定，且核心动作在主界面也可达 |
| **dark canvas 研究**（ToolPix/Chalkboard） | 暗色画布降低眼疲劳、投影对比高、彩色在深底上更跳 | 暗底 + 语义色（红=阻塞/绿=完成/黄=待办）天然契合白板工作流 |
| **designmd · Whiteboard 风格库** | 禁用纯黑、accent 饱和度≤80%、用图标系统而非 emoji、hover 抬升 + 8% 加深 | 与我们的 token 纪律一致（off-black、单 accent、无 emoji） |

**共同结论**：2026 高级白板 = 暗色优先 + 单一 accent + 边框代替阴影 + 浮动/可折叠工具条 + 右侧样式面板 + 底部缩放与 minimap + 完善的上下文菜单。这与 MarkCraft 既有的 Calm Premium 体系完全同构，**无需引入新调性**，只需把白板从"标签堆"升级为"工具完备的创作工作台"。

## 1. 现状诊断（白板帧 5:180，主板 713037613352052）

帧结构（1440×900）：标题栏 5:181(34px) + 侧边栏 5:187(240) + 内容区 5:191(1200×866)。
内容区内部：顶部工具栏 5:192(1200×44) + 画布区 5:198(1200×822)。

**问题清单（为何"简陋"）：**
1. **工具栏是裸文本**：`图形/画笔/橡皮/文字` 只是 4 个 TEXT 节点，无图标、无按钮态、无激活/悬停、无分组、无工具提示。一眼像线框占位。
2. **工具集残缺**：无 选择/抓手、便利贴、连接线/箭头、图片、形状库、撤销重做、演示、分享。仅 4 个词。
3. **画布空白无语境**：2 张相同表面卡片 + 2 条纯蓝折线，无点阵网格、无 float 工具、无缩放控件（仅"100%"文字）、无 minimap、无样式面板、无图层/模板。
4. **无属性面板**：选中元素后无法改描边色/填充/线宽/字体——白板最核心的"创作"能力缺失。
5. **视图切换形同虚设**：仅一个"视图: 看板 ▾"文本，实际产品支持 看板/脑图/时间线 三视图。
6. **无协作/空态/上下文菜单**：无在线头像、无空画布引导、无右键菜单暗示。
7. **视觉扁平无层级**：卡片全等、连线无箭头无标签、全靠色块，缺乏深度与"工作台"质感。

## 2. 风格定位

**Studio Canvas / 创作工作台** —— MarkCraft Calm Premium 家族第四成员，与仪表盘（Bento）、日记（Sanctuary）、知识图谱（Neural Atlas）**同源异情绪**：

- **同源**：复用 `--mc-*` 暗色 token（page/surface/panel/border/text/accent/语义色）、边框代投影、4px 间距基、圆角梯度、单 accent 克制用色。
- **异情绪**：白板是**"动手创作"**场景，相比日记的"静谧"、仪表盘的"冷静"，它更**工具前置、信息密度高、有工作节奏感**——但通过暗底 + 留白 + 单 accent 维持高级克制，不滑向 Miro 式花哨。

**设计三原则：**
- A｜工具前置但不喧宾：图标工具条 + 可折叠样式面板，创作时一切在手边，不创作时隐入背景。
- B｜语义色即工作流：红=阻塞 / 绿=完成 / 黄=待办 / 蓝=进行中——用既有语义 token 表达白板状态，不新增调色板。
- C｜边框代投影 + 点阵指引：暗底上以 1px 边框与极淡点阵建立空间，避免重投影带来的廉价感。

## 3. 色彩与排版

### 色彩（沿用 --mc-*，不新增）
| 角色 | Token | 值 | 用途 |
|---|---|---|---|
| 页面底 | `--mc-page` | `#0E0F17` | 画布底 + 外壳 |
| 表面 | `--mc-surface` | `#1A1C24` | 卡片/便利贴/面板底 |
| 面板 | `--mc-panel` | `#14161F` | 工具栏/样式面板底 |
| 边框 | `--mc-border` | `#292E30` | 1px 描边（代替阴影） |
| 主文字 | `--mc-text1` | `#E6E8EF` | 标题/正文 |
| 次文字 | `--mc-text2` | `#8A8F9C` | 标签/提示/坐标 |
| 强调 | `--mc-accent` | `#5B7CFA` | 激活工具/选中/主操作/进行中 |
| 成功 | `--mc-success` | `#1FA45C` | 完成态便利贴/状态 |
| 警告 | `--mc-warning` | `#E0A23B` | 待办态便利贴/状态 |
| 危险 | `--mc-danger` | `#E5564B` | 阻塞态/删除确认 |
| 点阵 | accent @ 6% | `rgba(91,124,250,0.06)` | 画布 dot-grid |

**accent 全屏 ≤ 2~3 处**（激活工具 + 选中描边 + 主按钮）；语义色只用于"状态标签/便利贴角标"，不用于装饰。

### 排版
- 字体族：UI = Inter（中文 PingFang SC / 微软雅黑回退）；坐标/尺寸等宽 = JetBrains Mono。
- 字号：工具栏标签 13 / 面板标题 12 SemiBold / 卡片标题 15 SemiBold / 卡片副文 13 Regular / 缩放数字 12 Mono。
- 字重：400 正文、500 UI 控件、600 标题、700 仅大数字（如缩放百分比不需要）。
- 行高：卡片正文 1.5；面板列表 1.4。

## 5. 组件结构

### 5.1 顶部工具栏（5:192，重做）
- **左·工具组**（图标按钮 32×32，gap 4，圆角 8）：选择(默认激活·accent 描边) / 抓手 / 画笔 / 形状▾(下拉：矩形·圆·菱形·箭头·连线) / 文本 / 便利贴 / 连线 / 图片 / 橡皮。激活态=accent 描边 + accent 文字；悬停态=surface 填充 + 抬升。每个带 tooltip。
- **中·面包屑 + 协作**：`白板 / 产品迭代 v2` + 1~2 个协作者头像（accent 圆形，首字母）。
- **右·操作组**：撤销 / 重做（禁用态 text2）/ 视图切换 `看板▾`(看板·脑图·时间线) / 演示 / 分享(accent 主按钮) / `⌘K` 胶囊。

### 5.2 画布区（5:198，重做）
- **点阵网格**：page 底上叠极淡 accent 点阵（圆点 r=1, 间距 24），建立空间感且不抢内容。
- **示例内容**（演示工具集，非真实数据）：
  - 便利贴 ×2：待办(警告黄角标)「需求梳理 / 用户故事+验收标准」、进行中(accent 角标)「原型设计 / 高保真界面稿」。
  - 圆角矩形(完成·success 绿描边)「接口联调」。
  - 形状(阻塞·danger 红描边)「依赖后端」。
  - **连线 ×2**：带箭头 + 标签（如「依赖」「blocked by」），accent 或中性 `#26292F` 描边。
- **选中态示意**：其中一个元素带 accent 选中描边 + 控制点（8 个小方块）——传达"可编辑"。

### 5.3 浮动样式面板（新增，5:xxx）
- 三标签页：样式 / 模板 / 图层。
- **样式**：描边色(4 语义色块+自定义) / 填充(透明+4 色) / 线宽(细/中/粗) / 字体(默认/等宽) / 对齐(≡⌊⌋)。选中无元素时整体禁用（text2）。
- **模板**：6 个缩略卡（流程图/用户旅程/脑图/看板/线框/SWOT），点击插入。
- **图层**：层级列表（元素名 + 可见/锁定 图标），支持拖拽排序（视觉示意）。

### 5.4 底部缩放条 + minimap（新增）
- 缩放：`[−] 100% [＋] [适应]`（accent 数值、按钮圆角 8）。
- minimap：右下小窗，显示全画布缩略 + 当前视口框（accent 描边），点击/拖拽导航。
- 帮助 `?`：打开快捷键/上下文菜单说明。

### 5.5 上下文菜单（新增，右键示意）
- 分组（NNGroup 准则）：`复制 / 粘贴` ‖ `置于顶层 / 置于底层 / 上移一层` ‖ `锁定 / 解锁` ‖ `删除`（danger）。
- 锚定在点击点、不遮挡选中对象；核心动作（删除/复制）在主界面或键盘也可达。

### 5.6 空状态（新增）
- 画布空时居中：`开始你的白板` + 副文 `拖入便利贴，或按 N 新建 · 双击空白处快速输入` + 「从模板开始 →」accent 按钮。

## 6. 核心视觉元素

1. **图标工具条**（替代裸文本）—— 32px 图标按钮，激活=accent 描边，建立"这是工作台"的第一印象。
2. **点阵画布** —— 极淡 accent 点阵，零成本建立空间纵深，暗底不刺眼。
3. **语义色便利贴/状态角标** —— 红/绿/黄/蓝表达工作流状态，是白板独有的"情绪"，仍守在 token 内。
4. **浮动样式面板** —— 把"创作能力"具象化（描边/填充/线宽/字体/对齐），可折叠保持克制。
5. **连线箭头 + 标签** —— 从"纯蓝折线"升级为带方向、带语义标签的关系线。
6. **minimap + 缩放条** —— 无限画布的导航标配，给"掌控感"。
7. **选中描边 + 控制点** —— 传达可编辑性与精确性。

## 8. 交互策略（实现层，画布仅示意）

- 工具切换：图标按钮激活态（accent 描边），快捷键 V/H/P/R/T/N/A/I/E。
- 选择：点击选中→accent 描边 + 8 控制点；框选多选；Shift 加选。
- 连线：从元素锚点拖出→箭头 + 自动路由 + 标签可编辑；hover 高亮关联。
- 样式面板：实时改选中元素；无选中时禁用。
- 缩放/平移：滚轮缩放、空格拖拽、minimap 导航；缩放数值 accent。
- 上下文菜单：右键锚定、分组、分隔线、核心动作冗余可达。
- 模板：点击插入到视口中心；图层列表拖拽排序。
- 尊重 `prefers-reduced-motion`：微交互 <300ms，关闭时仅切态无动画。

## 9. 响应式

- **桌面（≥1024）**：顶部工具栏 + 画布 + 右侧浮动样式面板 + minimap（本方案目标）。
- **平板（640–1023）**：样式面板转为底部 sheet / 抽屉，minimap 收起为图标。
- **移动（<640）**：工具栏转为底部图标栏（可横滑）；样式/图层转全屏 sheet；画布转纵向缩放优先。

## 10. 诚实边界（画布画不出的，属视觉真值）

Ardot 画布是矢量静态板，以下需 React + Tailwind 实现时补回：
- 真实点阵网格渲染（现为静态点示意）、图标字体（现用方块/文字占位）、hover 抬升微交互、accent 描边发光、
- 连线自动路由/箭头/标签跟随、选中控制点拖拽、minimap 实时缩略、模板缩略预览、
- 上下文菜单弹出动画、面板折叠过渡、协作头像实时光标。
- 这些在方案 + 后续 HTML 原型中落地为写实视觉真值。
