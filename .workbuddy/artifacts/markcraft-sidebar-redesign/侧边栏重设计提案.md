# MarkCraft 侧边栏颠覆性重设计提案

> **设计者**：UI Designer ｜ **日期**：2026-08-10 ｜ **对象**：MarkCraft 桌面壳界面稿 `713037613352052`
> **目标**：打破"功能入口集中于左侧 240px 宽栏"的常规范式，在不牺牲可用性的前提下，用更具巧思的布局强化产品差异与品牌辨识度。
> **说明**：当前 Ardot 画板 MCP 工具临时不可用，本轮先交付「分析 + 灵感 + 替代方案」研究产出；方案落地（改母板结构）待工具恢复后执行。现状侧边栏模块依据产品规格与工作记忆重建。

---

## 0. 一句话结论（给忙碌的人）

**推荐方案 A「图谱脊柱 / Graph-Spine」**：撤掉常驻左宽栏，改为一条 56px 的"书脊"脊（呼应"雕琢笔记"的书籍 craft 隐喻），以**知识图谱作为产品首页与导航脊柱**；全局 ⌘K 命令面板接管长尾导航与动作；右栏做"情境上下文面板"（选中笔记才浮现反向链接/大纲/文件树）；底部一条拇指友好的极简 dock 常驻「今日 / 搜索 / 设置」。

这让 MarkCraft 的签名能力（双向链接知识图谱）从"二级视图"升格为"一级导航"——直接区别于 Obsidian / Notion 把图谱藏起来的做法，是最高性价比的品牌差异化动作。

## 1. 现有侧边栏内容模块解构

当前桌面壳为「顶部标题栏（5:216）+ 左侧 240×866 宽栏（5:222）」的常规结构。侧栏内承载的模块可归为 5 类：

| 模块类别 | 具体入口 | 现状位置 | 使用频率 |
|---|---|---|---|
| **品牌区** | Logo / 工作区名 | 侧栏顶部 | 低（一次性识别） |
| **模式导航** | 编辑 / 白板 / 知识库 / 图谱 / 博客 / 仪表盘 / 每日笔记 | 侧栏主列表 | 高 |
| **内容树** | 文件夹树 / 笔记列表 / KB 文件夹 | 侧栏中部（5:227） | 高 |
| **工具入口** | 全局搜索 / 模板 / 导入迁移 | 侧栏（搜索在顶或底） | 中高 |
| **系统区** | 设置 / 主题切换 / 密度切换 | 侧栏底部 | 低（偶发） |

**痛点诊断**：
- 7 个模式 + 内容树 + 工具 + 系统全挤进左栏 → 随功能增长必然变成"杂乱抽屉"（Raycast/Linear 论文称为 *sidebar overflow*）。
- 图谱、白板这些 MarkCraft 的**差异化资产**被压成和普通入口平级的列表项，辨识度被稀释。
- 左栏常驻占用 240px，挤压了编辑/画布的"作品画幅"，与 Calm Premium 追求的"专注、低噪"相悖。

## 2. 联网灵感（5 个范式，提炼自 Raycast / Linear / Arc / Figma / Scrintal / iamtired 等）

| 范式 | 核心做法 | 对 MarkCraft 的可用度 |
|---|---|---|
| 命令面板即主要导航 | ⌘K 索引动作+导航+搜索，模糊匹配，最近/频繁置顶 | ⭐⭐⭐ 极高——直接解决侧栏溢出 |
| 上下文面板 | 控件贴着被操作对象（右栏），而非全局菜单 | ⭐⭐⭐ 极高——双链/大纲天然贴合 |
| 全幅画布 | chrome 隐身，作品即导航，⌘K 跳转 | ⭐⭐ 中高——适合编辑/白板态 |
| 空间工作台 | 无限画布，笔记即节点、连线即双链 | ⭐⭐ 中——最激进，需渐进引导 |
| 极简底栏 / 拇指优先 | 底栏常驻 2–3 个动作，移动端启示 | ⭐⭐⭐ 极高——桌面也能用，thumb-friendly |

## 3. 三套颠覆性替代方案

### 方案 A｜图谱脊柱 Graph-Spine（★推荐）
- **左栏（240px）→ 书脊（56px）**：仅放品牌 mark + 3 个核心模式图标（编辑 / 白板 / 图谱），accent 高亮当前模式。
- **首页 = 全局知识图谱**：启动默认落在可缩放图谱/空间画布，节点=笔记、连线=双链。导航=在图谱上点击/聚焦/缩放。
- **右栏 = 情境上下文面板**：选中某笔记时右栏浮现其反向链接、大纲、所在文件夹树；未选中时右栏隐身（渐进披露）。
- **底栏 dock**：常驻「今日 / ⌘K 搜索 / 设置」三枚，拇指可达。
- **⌘K 命令面板**：接管全部长尾导航（切到博客/仪表盘/每日笔记/模板/导入）+ 动作（新建/导出/换主题）。

### 方案 B｜⌘K 优先 + 边缘窥探 Command-First
- **彻底移除常驻左栏**。全局 ⌘K 命令面板（索引所有导航+动作+搜索）成为唯一主入口。
- **左缘留 8px 窥探脊**：hover/手势滑出瞬时导航浮层（peek），平时完全隐身，最大化内容画幅。
- 上下文动作走右栏（同方案 A）。最"桌面原生 + 键盘优先"，呼应 Raycast/Cursor。

### 方案 C｜空间工作台 Spatial Workbench（最激进）
- 整应用即一张无限画布：编辑器、白板、图谱、笔记卡都是画布上的浮窗/节点，无固定"页面"概念。
- 顶部仅一条命令条 + 视图胶囊。最契合"思考工具"定位，但上手成本最高，必须配首启引导。

> 另有**方案 D｜反置右栏 Inverted Chrome**（导航从左侧搬到右侧，左留给编辑器）作为保守备选，但差异化弱于 A，此处不展开。

## 4. 内容模块重分配映射（以方案 A 为准）

| 原左栏模块 | 新位置 | 交互形态 |
|---|---|---|
| 品牌 / 工作区名 | 书脊顶部 mark + tooltip | 静态识别 |
| 模式：编辑 / 白板 / 图谱 | 书脊 3 图标（核心） | 常驻、accent 高亮 |
| 模式：博客 / 仪表盘 / 每日笔记 | ⌘K 命令 + 书脊"更多"溢出 | 键盘/命令 |
| 文件夹树 / 笔记列表 | 右栏"文件"可折叠面板（情境） | 选中才展开 |
| 反向链接 / 大纲 | 右栏上下文面板（选中笔记浮现） | 情境、渐进披露 |
| 全局搜索 | ⌘K（首选）+ 底栏搜索图标 | 键盘优先 |
| 模板 / 导入迁移 | ⌘K 命令 / 右栏"工具"分组 | 命令 |
| 设置 | 底栏图标 + ⌘K | 偶发 |
| 主题 / 密度切换 | 顶栏胶囊 / 右栏底部 | 情境 |
| 知识图谱 | **升格为产品首页与导航脊柱** | 主交互面 |

## 5. 推荐方案 A 布局骨架规格

- **窗口顶栏（36px）**：左品牌 mark；中部分段胶囊（编辑 · 白板 · 图谱 · 博客 · 仪表盘）；右侧 ⌘K 触发 + 主题/密度。
- **书脊（56px）**：垂直排列 编辑 / 白板 / 图谱 三图标，激活态 accent 描边 + 左 2px accent 指示条。
- **主区（flex）**：默认=全局图谱画布（含 minimap 缩略导航）；进入编辑/白板态时全幅承载对应画布。
- **右栏（≤280px，可隐藏）**：三段——反向链接 / 大纲 / 文件树，随选中态渐进披露。
- **底栏 dock（居中，~240px）**：今日 · ⌘K 搜索 · 设置。
- **密度/主题**：沿用现有 `data-density` + 跟随系统主题，不新增控件。

## 6. 可用性与上手成本评估

| 维度 | 方案 A | 方案 B | 方案 C |
|---|---|---|---|
| 新手直观度 | 中（图谱需引导） | 中低（依赖键盘） | 低（范式最陌生） |
| 老手效率 | 高 | 极高 | 高 |
| 品牌差异化 | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐ |
| 实现风险 | 中 | 低 | 高 |
| 改造成本 | 中 | 低 | 高 |

**防迷路设计（保证可用）**：
- 首启 coachmark 提示 ⌘K；图谱提供 minimap 与"回到首页"入口。
- 书脊 3 图标 + 底栏 3 图标覆盖 90% 日常操作，鼠标用户无门槛。
- 右栏折叠态有明确"展开"提示，避免信息丢失感。

---

## 7. 品牌辨识度强化点

- **"书脊"隐喻**：56px 脊呼应"笔记/书"的 craft 质感，与 MarkCraft「雕琢笔记」命名形成视觉双关。
- **图谱即门面**：把别人藏起来的差异化资产放到第一屏，用户一眼记住"这是会思考的笔记工具"。
- **Calm Premium 一致性**：新布局沿用既有 token（bg-canvas / accent / 字距 -2% / 线性 SVG 图标），不破坏已建立的视觉系统。

---

## 8. 风险与缓解

- **图谱过载**：>500 节点低端设备卡顿 → 沿用现有 LOD/裁剪/空间索引优化，默认聚类视图。
- **发现性**：新用户找不到功能 → ⌘K coachmark + 右栏渐进披露 + 首启引导。
- **右键/命令面板无障**：保证焦点陷阱、ARIA、44px 触控目标（已纳入 Calm Premium 规范）。
