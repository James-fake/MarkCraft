## 修复知识库"发布博客"页面跳转问题
- **问题**: 知识库详细界面（KbDashboard）点击"发布博客"后，先跳到知识库管理界面（KbManager），需手动退出才能看到博客工作室（BlogStudio）
- **根因**: `handlePublishKbBlog`（App.tsx）调用 `setActiveKbId(null)` 但未关闭 `showKbManager`，导致 `showKbManager && !activeKbId` 为 true → KbManager 挂载；KbManager 与 BlogStudio 同为 `z-index: 200`，但 KbManager 在 DOM 中排序更靠后，覆盖了 BlogStudio
- **修复**: 在 `handlePublishKbBlog` 中增加 `setShowKbManager(false)`，阻止 KbManager 挂载
- **上下文数据**: `kbBlogFiles` 在跳转前已设置，通过 `currentFile={kbBlogFiles ?? blogCurrentFile}` 传递给 BlogStudio，无需额外修改
- **修改文件**: `src/App.tsx` 第 376-381 行

## 优化：关闭博客工作室后返回知识库详细页面
- **问题**: 从知识库详细页面点击"发布博客"进入 BlogStudio 后，关闭 BlogStudio 会回到主页，而非知识库详细页面
- **根因**: `handlePublishKbBlog` 清空了 `activeKbId` 和 `showKbManager`，BlogStudio 的 `onClose` 只做了 `setShowBlogStudio(false)` + `setKbBlogFiles(null)`，没有恢复 KB 状态
- **约束**: KbDashboard 也是 `position: fixed; z-index: 200`，不能同时挂载 KbDashboard 和 BlogStudio（DOM 顺序更靠后的会覆盖）
- **修复**: 新增 `kbBlogSourceId` 状态变量，打开 BlogStudio 前保存来源 KB ID，关闭时恢复 `activeKbId` + `showKbManager`
- **修改文件**: `src/App.tsx`（3 处：状态声明、handlePublishKbBlog、BlogStudio onClose）

## 优化 Canvas 白板加载体验
- **问题**: 首次打开 Canvas 白板（v2）时出现 2-4 秒"加载白板..."提示界面
- **根因**: `CanvasViewV2` 使用 `React.lazy` 懒加载，canvas-v2 模块含 70+ 文件且依赖 tldraw 库，首次加载 chunk 需 2-4 秒；Suspense fallback 显示了"加载白板..."文字
- **修复**: 
  1. 在应用启动时预加载 canvas-v2 chunk（`import('./features/canvas-v2/CanvasView')`），与 MermaidRenderer 预加载模式一致
  2. 将 Suspense fallback 从"加载白板..."div 改为 `null`，移除可见加载提示
- **修改文件**: `src/App.tsx`（2 处：第 69-70 行预加载、第 1066 行 Suspense fallback）
