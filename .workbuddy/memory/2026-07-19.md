## P23：修复浮动工具泡删除图形时报 "Application Error: Rendered fewer hooks than expected"
- 现象：画布插入椭圆/任意图形，选中后点浮动菜单「🗑删除」，或删除其他内容时整个界面崩溃（"Rendered fewer hooks than expected. This may be caused by an accidental early return statement."）。
- 根因：`FloatingToolbar.tsx` 在 `useLayoutEffect`（智能避让定位 hook）**之前**写了两个提前 `return null`
  （`if (selectedIds.length === 0) return null` 与 `if (!bounds) return null`）。删除图形后 `selectedIds` 变空，
  该次渲染提前返回、跳过 `useLayoutEffect` → 比上一次渲染少调用一个 hook → React 抛 hooks 数量不一致崩溃。
- 修复：把所有 hook（`useState`×2、`useRef`、`useState(placement)`、`useLayoutEffect`）移到提前 return **之前**：
  - 无条件计算 `camera/vp/bounds` 及派生 `cardScreenX/Y/cardW/provisionalX/Y`（对空选中做 null 守卫，给默认值 0）；
  - `useLayoutEffect` 内部首行加 `if (selectedIds.length === 0 || !bounds) return` 守卫；
  - 真正「无选中即不渲染」的 `return null` 放到 `useLayoutEffect` 之后（满足「所有 hook 先于提前返回」规则）。
- 顺带修掉替换时误产生的 `const el = ref.current` 重复声明（TS2451）。
- 验证：`tsc --noEmit` 仅余 4 个预存无关错误，零新增；dev server 5173 HTTP 200（HMR 已加载）。

## P25：修复底栏工具高亮点击后立即更新（而非等真正绘制）
- 现象：点底栏「画笔/椭圆」等工具，图标高亮仍停在「选择」，要等你真正画一笔后才切到该工具。
- 根因：`currentToolId` 只在 `editor.store.listen` 的 **document scope** 回调里更新（`updateState`）；
  而 `editor.setCurrentTool('draw')` 改的是 `instance.currentToolId`，属 **session scope** 变更。

- 修复（`CanvasView.tsx`）：在 session scope 的 `editor.store.listen` 回调里补上
  `setCurrentToolId(editor.getCurrentToolId())`，使点击工具即同步高亮。

## P26：演示模式下禁止双击卡片进入编辑

- 根因：演示暗色底舞台（`zIndex:1500`）是 `pointerEvents:none`；`CanvasView` 在演示时把画布容器
  抬到 `zIndex:1600`（高于底舞台），所以 tldraw 画布在最上层、完全可交互，双击直达编辑。
- 修复（`PresentationViewer.tsx`）：在画布(1600)与顶/底控制条(2000/2001)之间新增一层
  **透明全屏捕获层 `zIndex:1900`，`pointerEvents` 默认开启**：双击/点击被它吞掉，不到达画布
  → 不会进入编辑；同时把左右滑动手势挂到该层，保留全屏滑动切换。`onDoubleClick` 也 `preventDefault` 双保险。

## 第二十一轮：所有侧边栏支持点击画布空白自动折叠

  双击才是 `type:'click'`（`name:'double_click'`）；点击图形时 target 为 `shape`/`selection`。

  `info.type==='pointer' && info.name==='pointer_up' && info.target==='canvas'` 时
  `setDrawerOpen(false)` + `setFilePanelOpen(false)` + `setRightRailOpen(false)`。
- 兼容性：点击图形（target 非 canvas）不触发，不影响选中交互；若框选结束于画布（selectedIds>0）
  会自动展开右栏 effect 重新打开，净效果仅"真正的空白点击"才折叠；演示模式有捕获层吞掉指针，不会误触发。
