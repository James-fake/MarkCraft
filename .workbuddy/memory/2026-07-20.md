# 2026-07-20 修复 Excalidraw 白板工具栏重复与自定义工具失效

## 问题
Excalidraw 迁移后：①原生工具栏与自定义 BottomBar 重复；②点击原生/自定义工具都无法工作。

## 根因（4 处）
1. Excalidraw 原生 UI 未隐藏（tldraw 路径用 `tldrawComponents` 隐藏，Excalidraw 路径无等价处理）。
2. `CanvasEngine.setCurrentTool` 直接把 tldraw 工具名透传给 `api.setActiveTool`，Excalidraw 不识别（`select`≠`selection`、`draw`≠`freedraw`、`geo`≠`rectangle/ellipse`、`note` 无原生工具）。
3. 引擎内工具名不一致：`setCurrentTool` 存 tldraw 名，`syncFromScene` 存 Excalidraw 名 → `OverlayCards` 的 `interactive` 判断失效，卡片无法点击/拖拽。
4. 便签(note)走切换工具而非创建卡片；`updateBinding/createBinding` 调用了 Excalidraw 并不存在的 `api.updateElement`（运行时会崩）。

## 修复
- 新建 `engine/excalidraw-hide-ui.css`（隐藏 `.layer-ui__wrapper` 等），在 `ExcalidrawCanvas.tsx` import。
- `CanvasEngine.ts`：新增 `TL_TO_EXCALIDRAW`/`EXCALIDRAW_TO_TL` 双向映射 + `pendingGeo` 字段；`setCurrentTool` 正向映射并统一存 tldraw 名（note→select）；`syncFromScene` 反向映射；默认工具 atom 改 `select`；`setStyleForNextShapes` 记录 geo 子形状；新增 `patchElement()` 用 `updateScene` 替换不存在的 `updateElement`。
- `OverlayCards.tsx`：`interactive` 判断改用 tldraw 名（`select`/`hand`/`eraser`）。
- `BottomBar.tsx`：新增 `onCreateNote` prop，`note` 工具改为调用它创建卡片；`CanvasView.tsx` 传 `onCreateNote={handleCreateCard}`。
- `engineTypes.ts`：`updateElement` 标记为可选（真实 API 无此方法）。

## 验证
- `tsc --noEmit` 全项目 0 错误。
- `engineNodeTest.ts` 扩展至 37 断言（新增 [10] 工具名映射双向），全过。
- dev server（vite.smoke.config）localhost:5173 返回 200，已预览。

## 关键结论（复用）
- Excalidraw 合法原生工具名：`selection/rectangle/diamond/ellipse/arrow/line/freedraw/text/image/eraser/hand/frame/embeddable/laser`。
- Excalidraw 命令式 API **没有** `updateElement`，单元素修改必须走 `updateScene` 全量回写。
- 引擎内部工具名统一采用 tldraw 命名（BottomBar/OverlayCards 依赖），与 Excalidraw 交互处集中转换。
