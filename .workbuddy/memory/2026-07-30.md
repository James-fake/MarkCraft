## 修复日记页"年"滚轮无法滚动
- 根因：仅"年"滚轮通过 WheelPicker 的 quickTop/quickBottom 在 .dv-wheel 内部绝对定位叠加了"↑今天/↓今天"按钮（z-index:6，覆盖滚轮顶/底约18px）。按钮的 onPointerDown stopPropagation 阻止事件冒泡到滚轮的拖拽处理器，且按下后松手触发 onClick→onToday 把年份弹回今天，导致在顶/底区域抓取滚动时整条滚轮"失效/跳动到今天"。月/日滚轮无按钮故正常。
- 修复：将"今天"快捷跳转按钮从滚轮内部抽离，改为滚轮上/下方的独立内联药丸按钮（.dv-wheel-quick 去掉 position:absolute/.top/.bottom，改为 flex 子项）；滚轮表面不再被任何元素覆盖，拖拽/鼠标滚轮/触摸全部恢复。同时删除 WheelPicker.tsx 中已无人使用的 quickTop/quickBottom 支持（消除该危险模式）。
- 验证：tsc --noEmit 零错误；vite build 成功（dist-yearfix-* 临时目录，清理被 safe-delete 拦截，待手动删）。

## 修复年滚轮「仅 2026 + 比月/日长」问题
- 根因1（仅 2026）：`minYear` 原逻辑 `Math.min(todayY, 首篇日记年份)`；当所有日记都在 2026 时 `minYear=2026`，yearItems 只剩 [2026]。改为 `minYear = Math.min(todayY - 5, 首篇年份)`（即 floor 固定为 todayY-5），保证年滚轮始终展示 2021–2026 共 6 年。
- 根因2（年滚轮比月/日长）：只有"年"列里叠加了 `↑今天/↓今天` 两个快捷按钮（flex 子项），撑高整列；月/日列无按钮，故三列不齐。删除年列两个按钮（顶部栏 `.dv-wheel-acts` 已有「↺ 今天」功能，冗余），使三列结构完全一致（滚轮+caption），三滚轮共用 `.dv-wheel`(height:188px) 尺寸统一。同时删除已无人使用的 `.dv-wheel-quick` CSS。
- 验证：tsc --noEmit 零错误；vite build 成功（dist-yearuniform-* 临时目录，清理被 safe-delete 拦截，待手动删）。

## 滚轮循环滚动模式（loop）
- 需求：月/日滚轮改为循环滚动——滚过 12 月无缝回 1 月，1 月往上回 12 月；过渡平滑无卡顿/跳变。年份为有限范围，保持非循环。
- 实现（WheelPicker.tsx 新增 `loop?: boolean`）：
  - loop 时渲染 3 段重复列表（`renderCount = 3*len`，虚拟索引窗口 [0,3len)），子项按 `actual=((k%len)+len)%len` 取标签，沿用同一套 3D 透视。
  - 无缝核心：`applyOffset` 内做循环归一化——保证中心虚拟索引始终落在 [len,2*len)，越界即整段平移 `±len*itemHeight`；因内容每 `len*itemHeight` 重复一次，平移前后像素完全一致 → 视觉无缝、无跳转。
  - 拖拽/惯性/滚轮均取消原有限位钳制（loop 模式放行自由 offset，由 applyOffset 归一）；snap/animateTo 提交的索引改为 `((raw%len)+len)%len` 取模再 onSelect。
  - 外部联动（如热力图跳月）：`offsetForIndex` 选离当前滚动位置最近的循环落点（i / i+len / i+2len 取最近），避免整段长距离旋转。
  - 非 loop 路径（年份 + 原逻辑）完全不变：窗口 [0,len)、minOff/maxOff 钳制、commit 用 clampIndex。
- DiaryView：月、日 WheelPicker 传 `loop`；年份不传（有限范围 2021–2026）。
- 验证：tsc --noEmit 零错误；vite build 成功（dist-loopyear-* 临时目录，清理被 safe-delete 拦截，待手动删）。

## 年份滚轮改为无限循环（loop）
- 需求：年滚轮在滚到 maxYear(=todayY) 或 minYear 边界时无法循环，要求向上/向下到边界无缝衔接（maxYear↔minYear 循环），交互流畅自然。
- 实现：
  - DiaryView 的「年」WheelPicker 加 `loop`（与月/日一致）。复用既有通用循环算法（3 段重复 + 取模提交）。
  - 放宽年份范围使循环有实际意义：`minYear = Math.min(todayY - 50, 首篇日记年份)`，maxYear=todayY 不变；区间约 50 年，越界极少触及，触及时平滑衔接。年份可回溯到任意历史日记年份。
  - WheelPicker.applyOffset 的循环归一化由「8 次 while 平移」改为「取模直接计算」：`vi=(center-o)/itemHeight; norm=((vi%len)+len)%len; o=center-(norm+len)*itemHeight`，对较大 len（年份）也精确稳定、不会因偏移过大越界。
- 验证：tsc --noEmit 零错误；dev server http://localhost:5173/ 在线（HMR 已加载）。

## 年份滚轮范围固定为 1~4001（硬边界，非循环）
- 需求变更：年份滚轮不再无限循环，改为硬范围 minYear=1、maxYear=4001，滚动不可超出。
- 实现：
  - DiaryView：`minYear=1; maxYear=4001`（常量，移除对 todayY/首篇年份的依赖）；年份 WheelPicker 去掉 `loop`（恢复非循环钳制：拖拽 ±40 余量、惯性、鼠标滚轮均在 [minOff,maxOff] 硬钳制，到 1/4001 即停）。删除不再使用的 `todayY`。
  - 性能：4001 项非循环中 applyOffset 原每帧遍历全部子项（4001 次），改为「视口窗口化」——仅重算 |k - cvi| <= visible+3 的可见项，视口外项仅置 opacity:0（且只在未为 0 时写），保证超长列表滚动依旧流畅；月/日循环模式（3 段、子项少）不受影响。applyOffset 依赖数组补 `visible`。
