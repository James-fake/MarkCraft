- 修复：改用 **portal + fixed 定位** 脱离滚动容器裁剪。
  - 新增 `moodBtnRef` + `moodPop` 状态；`useLayoutEffect` 监听 `moodPickerFor`，按 `getBoundingClientRect` 计算 `top/left`：右对齐（`left=min(r.right, innerWidth-estW-8)`）、下方空间不足则翻到上方（`above`）；监听 `scroll(capture)/resize` 实时重算。
  - `useEffect` 加外部 mousedown / Escape 关闭。
  - 弹层 `createPortal(..., document.body)`，`role=menu` + `menuitem`，加 `flex-wrap:wrap; max-width:260px`。

## 优化：日期滚轮性能 + 3D 凸出特效
- 痛点：原 `WheelPicker` 年滚轮（1~4001，非 loop）渲染全部 4001 个 DOM 节点，`applyOffset` 每帧遍历全部 children → 卡顿。
- 方案：**池化虚拟列表**。固定渲染 `POOL=visible*2+8`（≈18）个 `.dv-wheel-item` 节点，与总项数解耦；每帧按 offset 计算 `startVi`，仅更新池内节点文本(虚拟索引 `mod`/clamp)+`transform(translateY+translateZ+scale+rotateX)`+opacity/blur/color/textShadow。loop 模式去掉 3 段重复渲染，改虚拟索引任意整数取模无缝循环。
- **3D 凸出特效**：`.dv-wheel` 加 `perspective:800px`；选中项 `scale(1.35)+translateZ(42px)` 浮出 + 高光阴影；相邻项 `rotateX(±45°)` 倾斜 + 渐隐 + 模糊；`rel=vi-cvi` 浮点距离驱动缩放**连续**过渡 → 丝滑。`.dv-wheel-item` 加 `backface-visibility:hidden`。
- 验证：tsc 零错误；滚轮/日记集成测试 20 通过；全量回归 **179 通过/2 跳过**；`vite build` 成功。dev server 热更新在线（HMR）。
- 新增项目铁律 MEMORY.md #8：滚轮必须池化虚拟渲染，禁止全量渲染 items。

## 优化：滚轮悬停缩放联动
- 需求：鼠标悬停年/月/日任一滚轮时该滚轮放大突出，其余两个缩小淡出，提升选择焦点感。
- 实现（纯 CSS `:has()`，零 JS、无性能负担）：`.dv-wheel-col` 加 `transition: transform/opacity 0.3s cubic-bezier(.22,1,.36,1)` + `transform-origin:center`。
  - `.dv-wheels:has(.dv-wheel-col:hover, .dv-wheel-col:focus-within) .dv-wheel-col:not(:hover):not(:focus-within) { transform:scale(.9); opacity:.55 }`（其余缩小淡出）
  - 同条件下 `:hover`/`:focus-within` 列 `transform:scale(1.14); opacity:1`（悬停项放大凸出）。focus-within 让键盘聚焦也触发，兼顾无障碍。
- 验证：tsc 零错误；dev server HTTP 200 热更新在线。外层 `.dv-card` 无 `overflow:hidden`，放大不被裁剪。

## 优化：滚轮/触摸统一惯性物理引擎
- 痛点：原 `onWheel` 仅 `offset -= deltaY*0.4` + 120ms 后 snap，**无惯性**，与触摸体验割裂，违背"统一体验"。
- 方案：鼠标滚轮与触摸滑动统一到**同一套基于速度的物理引擎**（共享摩擦/停止阈值/速度上限），两者只负责"注入初速度"，由同一个 `requestAnimationFrame` 滑行循环驱动；速度按指数衰减（天然 ease-out），归零后 `snap()` 吸附对齐。
  - 模块级常量：`WHEEL_FRICTION=0.94`（每16ms保留比例）、`WHEEL_STOP_V=0.02`、`WHEEL_TOUCH_BOOST=8`、`WHEEL_KICK=0.01`、`WHEEL_MAX_V=18`；`clampNum` 工具。
  - `velRef` 单一速度状态；`startMomentum()` 改为无参、读 `velRef` 的共享滑行循环（边界命中即清零速度并 snap）。
  - 触摸 `onPointerUp`：`velRef = clamp(dragVel * WHEEL_TOUCH_BOOST)`，慢放(<0.05)直接 snap。
  - 滚轮 `onWheel`：归一化 deltaMode(像素/行/页)→px，初速度 `kick = -d*WHEEL_KICK`，**累加**到 `velRef` → 快速连滚速度叠加、强烈连续滚动；停止后剩余速度自然衰减滑行。
  - `onPointerDown` 抓取时 `velRef=0` 终止残余滑行；删除旧 `wheelTimerRef` 及 120ms 定时器。
- 验证：tsc 零错误；滚轮+日记集成 20 通过；全量回归 **179 通过/2 跳过**；dev server 热更新在线。
