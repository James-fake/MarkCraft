## 博客工作室「自定义CSS」三模块无响应 — 根因与修复
- 现象：动画时间轴编辑器(KeyframeEditor)、CSS 变量参考/选择器参考(CssReference) 点击或操作无反应。
- 排查：三组件逻辑与回调(onInsertCss/insertAtCursor→handleDesignChange→setDesignConfig)均正确；jsdom 交互测试 4 例全绿（展开/插入/添加关键帧均触发回调）。`handleDesignChange` 为纯净 state 更新，无静默丢弃/拦截。无 pointer-events:none 或浮层覆盖侧栏。
- **根因（布局/滚动 bug）**：`BlogStudio.tsx` 侧栏内容滚动容器（flex:1 列项，约 L356）缺 `min-height:0`。flex 列项默认 `min-height:auto` 会撑开到内容高度而非受限滚动；嵌套 `sidebar-scroll`(maxHeight:100%) 此时解析为撑开后的全高、永不触发滚动 → 整个面板不滚动，底部内容被外层 `overflow:hidden` 裁切、不可达、点击无响应。
- 为何恰好这三：三者位于 `CssPanel` 最底部（VisualCssEditor/CssVariablesPanel/CssSnippets/ScopeSelector 之后），上方模块在可视区可交互，底部三被裁切 → 与用户报障完全吻合。
- 修复：① `BlogStudio.tsx` 该容器加 `minHeight: 0`，使其成为真正受限滚动视口，底部模块可滚动到达、可点击。② `CssReference.tsx` 修正 `CSS_SELECTORS` 中 `.post-content` 重复导致的 React key 冲突（按钮 key 改为 `${selector}-${i}`）。
- 顺带：同一 `min-height:0` 修复也使其他侧栏面板（StylePanel/ColorPanel 等）长内容可正常滚动。
- 验证：tsc 0 错误；全量回归 **672 passed / 2 skipped / 0 failed**（53 文件）。新增 `blogCssRefs.test.tsx` 作为三模块交互回归守卫。
- 注：保留 `blogCssRefs.test.tsx`（验证三模块点击触发回调）。

## 博客工作室「配色菜单」自身随调色盘联动变色 — 修复
- 现象：调色盘移动/选色时，不仅博客预览实时变色，配色菜单自身（滑块标签文字、滑块拇指、自定义色块边框/背景）也随所选颜色联动变色，属异常。
- 根因：`ColorPicker` 的 `SliderRow` 把 `color`（=designConfig.customColor）直接用于①滑块标签文字色 ②注入全局未作用域 `<style>` 的滑块拇指 background（该 style 写在 SliderRow 内、被渲染 6 次且无 class 作用域，会泄漏到其它面板的所有 range 输入框）③深浅/饱和/锐化滑块轨道渐变。`ColorPanel` 的自定义色块按钮边框/背景绑定 `customColor`，拖动调色盘时 `onColorChange` 立即切 `colorScheme='custom'` 且 `customColor` 持续变化 → 按钮边框/背景整块闪烁。
- 修复：
  - `ColorPicker.tsx`：`SliderRow` 移除 `color` prop；标签文字固定中性色 `rgba(255,255,255,0.6)`；新增固定强调色 `PICKER_ACCENT='#a78bfa'`；把 `<style>` 从 SliderRow 提到 `ColorPicker` 顶层只渲染一次，选择器作用域化为 `.mc-slider input[type=range]::-*`（不再泄漏到其它面板）；深浅/饱和/锐化轨道渐变改为固定中性色阶（去掉 `${color}`）。
  - `ColorPanel.tsx`：自定义色块按钮边框固定 `2px solid transparent`、背景固定 `swatchBg`；仅内部小方块(dot)显示 `customColor`（与 12 个预设色块一致，不污染菜单背景）。
- 保留（属调色盘/预览功能本身，非菜单装饰）：SV 面板圆点、色相条、hex 颜色预览块、hex 文本、预览卡（博客配色预览）。
- 测试：新增 `panels/ColorPanel.test.tsx`（5 例）守卫——标签文字色固定不引用所选色、`.mc-slider` 作用域化不外泄、轨道渐变不含所选色、自定义按钮边框固定不随 customColor 变、单击触发 colorScheme=custom。
