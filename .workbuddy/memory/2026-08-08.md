- **最对口技能/工具（可注入设计系统 + 桌面预览）**：
  - **Open CoDesign**（开源桌面 AI 设计工具，MIT，跨 Win/mac/linux）：12 内置设计 skill（仪表盘/数据表格/聊天/日历/编辑排版…）；支持注入自定义 `DESIGN.md` 设计系统（品牌值+token 写文件替代模型记忆）；桌面/平板/手机三视口；本地优先无遥测；点元素 pin 局部精修 + Agentic Design 读写真实工作区。
  - **Wonder**（桌面 App + Web）：AI 在画布建设计（非聊天代码 dump）；GitHub 仓库集成（读源码重建真实产品 UI）；设计 token 面板（导入 CSS 变量 / 导出 Tailwind/CSS/DTCG）；⌘K 命令面板。直接对接本项目 `src/styles/tokens.css`。
  - **ardot-ui-design + ardot-design-core**（用户已附加，零切换）：Ardot 画布产 Web App/设计系统稿，配 `ardot-design-to-code` 出 React/Tailwind，`ardot-dual-theme-responsive` 补深色+响应式。
- **代码优先生成**：Vercel v0（最干净 React+Tailwind+shadcn）、Subframe（code-native 确定性，MCP 喂设计系统）。
- **Web→桌面交互范式（须做成规则/skill 落地的部分）**：自定义无边框标题栏（`frame:false`+`titleBarStyle`+`-webkit-app-region:drag`）、原生右键 context menu（`Menu.buildFromTemplate`）、⌘K 命令面板、键盘优先、信息密度（多栏密集布局）、系统托盘/本地文件/拖放；Electron/Tauri/MōBrowser 包壳。
- **反「网页感」审美校准**：`web-design-skill`（oklch 感知均匀色彩 + 反陈腔黑名单）、UI/UX Pro Max、Impeccable.style `/polish`。
- **设计系统治理**：Tokens Studio + Style Dictionary + W3C DTCG（把 `--mc-*` token 正规化）、Storybook + Chromatic（组件目录 + 视觉回归）。
- 结论：Web→桌面重设计 = 方法论（UI/UX adaptation checklist）+ 允许注入自有设计系统的出图/出码工具；Open CoDesign 与 Wonder 是少数"桌面端原生 + 可注入 DESIGN.md"的突出选择。
