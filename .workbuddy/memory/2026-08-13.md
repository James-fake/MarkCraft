## MarkCraft 面板演示 · 波浪弯折底栏（∩ 环抱）几何/可见性修复

- **问题**：编辑界面（`#/editor`）的波浪底栏「没有正确正常显示」。
- **根因**：
  1. 初版已用内嵌 SVG 单 path 重写（`overflow:hidden` 裁弧 + 伪元素同色不可见 的旧坑已规避），但容器 `min-height:44px` + viewBox `0 0 1000 68` 缩放 ≈0.647 ⇒ 实体区塌到 ~28px，12px 统计文字溢出悬空到弧顶镂空区；
  2. SVG `fill="var(--mc-bg-panel)"` 与编辑区同色 ⇒ 整条底栏只剩 1px 描边，几乎不可见。
- **修复**（`src/showcase/showcase.css` + `panelsEditor.tsx`）：
  1. 底栏 `min-height` 44 → **68px**（viewBox 1:1，实体区≈38px 容纳统计文字；平直顶边 y=30 与两侧栏底齐平）；
  2. SVG `fill` → `var(--mc-bg-elevated)`（比编辑区亮一档，dock 表面清晰浮现）+ `stroke` → `var(--mc-border-subtle)` + 阴影 `0 -2px 6px rgba(0,0,0,.28)`；
  3. 胶囊 `.ed-wave-dock` 维持 `bottom: calc(100% - 46px)`，在 H=68 时稳坐弧顶拱桥（顶距弧峰 2px，不穿出容器顶）；
  4. 全局「底部」工具栏模式仍 `display:none` 本地胶囊，避免双胶囊。
- **验证**：tsc 仅既有 TS6133 告警、零新增；dev server `localhost:5173/showcase.html` → 200；底栏在 editor 路由无条件渲染、无重复规则。
- **待办**：浏览器实际预览截图确认弧形+信息栏+胶囊三者视觉对齐（环境无 headless 浏览器，未做像素级截图核验）。
