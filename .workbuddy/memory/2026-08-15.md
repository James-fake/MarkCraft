- **用户反馈**：「界面未能正常显示我要求的那个效果设计」——此前多轮实现（∩拱起/∪凹陷/平直环抱）均因**无 headless 浏览器无法截图核验**，只能靠用户反馈盲改，反复空转。

- **根因确认**（v1 截图）：底栏内容(左信息+右工具栏)在且正确，但**三面板底部是平直矩形、无任何弧形过渡**——用户要的「面板底部弯出凹槽」完全缺失。之前所有轮次只改了底栏自身样式，从未给面板底部加过弧线。
- **最终实现**（`panelsEditor.tsx` + `showcase.css`）：
  1. `.ed-footer` 改为 `flex-direction:column; position:relative; overflow:visible; margin-top:-10px; background:none; border:none;` —— 容器透明，轮廓由内部 SVG 提供；上提 10px 使弧线两侧高点与面板底边衔接。
  2. 内嵌 `<svg class="ed-footer-curve" viewBox="0 0 1000 52">` 一体绘制 ∪ 弧谷：
     - `<rect>` 填充凹槽本体渐变（`#232836 → #111319`，明显深于面板）；
     - `<path>` 绘制 ∪ 曲线（`M 0,0 L 320,0 C 400,0 435,48 500,48 C 565,48 600,0 680,0 L 1000,0 Z`），填充**纯色 `bg-panel`**(硬边不渐变) + **1.2px `border-subtle` 描边**勾勒弧形轮廓；
     - `preserveAspectRatio=none` 随容器宽度自由拉伸。
  3. SVG 加 `drop-shadow` 双层投影（`0 -3px 8px rgba(0,0,0,.28)` + `0 -1px 3px rgba(0,0,0,.18)`）⇒ 凹陷立体感。
  4. 内容行 `.ed-footer-row`：`margin-top:44px`(推到弧谷 y=48 以下)、`padding:6px 16px 10px`、`min-height:44px` ⇒ 信息栏+工具栏坐在凹槽底部同行。
  5. 工具栏 `.ed-dock` 保持 pill 样式（`bg-panel + border-subtle + radius-pill + 双层阴影`）。
- **迭代过程**（4 版截图对比）：
  - v1: 弧线存在但 bg-panel 与 bg-elevated 太接近 → 几乎不可见
  - v2: 加渐变+描边 → 仍太微妙
  - v3: 加深弧谷+增强投影 → 凹槽区域可见但弧线边缘糊（面板区用了渐变）
  - v4: **面板区改为纯色硬切 + 1.2px 亮描边 + 更深凹槽(52px)** → ✅ ∪ 弧线清晰可辨
- **验证**：tsc 无新增错误（仅既有 TS6133）；CSS 538/538 配平；Edge 截图确认 ∪ 弧谷 + 左信息栏 + 右胶囊工具栏三者视觉正确呈现。
- **经验总结**：
  1. **Windows 环境可用 Edge 无头模式截图**：`msedge --headless --disable-gpu --no-screenshot --screenshot=<path> --window-size=W,H --virtual-time-budget=N <url>` —— 以后不再盲改，每次渲染类改动都截图自检。
  2. **暗色模式下「相近色 = 不可见」是高频坑**：bg-panel(#14161F) vs bg-elevated(#1A1C24) 只差 ~6/通道，必须用 >15/通道的差值或加描边/投影才能让过渡可见。
  3. **SVG 面板延伸区必须用纯色硬切**：若用渐变（尤其底部渐暗），弧线边界会融入凹槽背景导致轮廓丢失。
