## 编辑器界面优化（三轮）· 布局对齐 + 固定功能（已完成）
- 用户反馈两点：①触发条遮挡行号、高度与编辑区不对齐；②要给文件/大纲菜单加「固定」按钮（点击后菜单常驻，不随点击他处/失焦收起）。
- 落地：
  - `.ed-main` 加 `padding-left: 18px` —— 左缘触发条独占一条「左通道」，编辑器（含行号槽）整体右移，行号不再被触发条遮挡。
  - `.ed-rail` 高度改为 `top: 34px; bottom: 0` —— 从面板标题栏（ep-head ≈34px）之下开始、到状态栏上沿结束，与编辑内容区视觉对齐（左右对称）。
  - 固定按钮：面板头原有 `ed-pin-btn` 的 `Icon.panelLeft/panelRight` 换成 **`Icon.pin`（图钉）**；`sidebarOpen`/`inspectorOpen` 即为固定态（面板显示条件 `open || peek`，固定后鼠标移出不收起）；`.ed-pin-btn.on svg { transform: rotate(45deg) }` 固定态旋转 45° 一眼可辨；⌘B/⌘J 仍可切换。
- 验证：tsc 仅既有 nav/I TS6133；served `Icon.pin`=2、`ed-pin-btn.*panelLeft`=0、CSS `top:34px`/`padding-left:18px` 生效；HTTP 200。
- 设计假设（可调）：rail 上沿 34px 假设 ep-head 高度；若用户想要满高或不同内嵌量，改 `.ed-rail` 的 top/bottom 即可。

## 编辑器界面优化（五轮）· 补齐左触发条上方空档（已完成）
- 用户反馈：左触发条上方（左通道内、标题栏 0–34px 高度）有一块空白。
- 根因：`.ed-main` padding-left 18px 后，左通道 y=0..34 区域既无触发条（34px 起）也无标题栏（18px 起）→ 露出应用底色。
- 落地：`.ed-rail-group-left .ed-rail::before` 伪元素补齐——高度 `var(--ed-rail-top)`、`background: var(--mc-bg-elevated)`（与 ep-head 同色调）+ `border-bottom: 1px solid var(--mc-border-subtle)`（与 ep-head 底边框连成一线）→ 标题栏视觉从左缘贯通到右缘，触发条悬挂其下；补齐区随触发条参与悬停。
- 配套：左右 rail 去掉 `border-top`（避免与标题栏底边双线），圆角改为上直角/内下圆角（左 `0 0 md 0`、右 `0 0 0 md`）保持对称。
- 验证：served CSS 含 `::before` cap；HTTP 200。纯 CSS 无 TS 变更。
