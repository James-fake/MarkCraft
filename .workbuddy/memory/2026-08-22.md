## 知识图谱 · 修复「功能切换不了」真根因 = pointer-events 继承（已完成）
- 上轮死区修复后用户仍点不了图标 → 重新定位：**真根因是 `.kg-rail-group { pointer-events: none }` 被面板继承**。`pointer-events` 是**可继承**属性：`.wb-inspector` 未显式声明时从容器继承 `none`，打开态（无 .closed）整个面板及图标/内容全部不可点击（点击穿透到下层图谱）；`kg-rail` 能用只因它显式写了 auto。
- 对照：编辑器 `.ed-rail-group.open .ed-sidebar/.ed-inspector { ... pointer-events: auto }` 有显式恢复，故从未中招；图谱 `.kg-rail-group` 漏写 → 从第一版起面板内容就一直点不动。
- 修复：`.kg-rail-group .wb-inspector { z-index:42; pointer-events:auto; }` + `.kg-rail-group .wb-inspector.closed { pointer-events:none; }`（closed 用更高特异性，防与 base .wb-inspector.closed 平级竞争）。上一轮的死区（right:30→12 重叠）也是真实问题，一并保留。
- **通用教训**：凡容器设 `pointer-events:none` 做透传（rail-group 模式），其浮层面板**必须显式 `pointer-events:auto`**（打开态），收合态再显式 none；否则面板看得到点不到。
- 验证：served `.kg-rail-group .wb-inspector{...pointer-events:auto}` + `.closed{pointer-events:none}` 生效；HTTP 200。
