## 知识图谱 GraphPanel 平移崩溃修复（2026-08-26 续）

用户报告：在知识图谱界面「滑动内容」时界面立即报错 `TypeError: Cannot read properties of null (reading 'tx')`，堆栈落在 `GraphPanel.tsx` + `basicStateReducer`（setState 更新函数内）。

**根因**：`onPointerMove` 的平移分支在 `setView` 的**更新函数**里读取 `panRef.current!.tx`（`GraphPanel.tsx:510`）。`onPointerUp` 会把 `panRef.current` 置 `null`；React 18 可能把该延迟更新函数在 `panRef` 已被清空之后才执行，于是闭包读到 `null.tx` 抛错。

**修复**：在调用 `setView` 前把 `panRef.current` 捕获进局部 `const start`（此时已 `if (panRef.current)` 保证非 null），更新函数内改用 `start.tx/start.ty`，彻底消除「更新函数执行时已为 null」的时序依赖。

**验证**：`tsc` EXIT:0；用 Edge headless + CDP（`--remote-debugging-port=9222` + 标准 `WebSocket` API 发 `Input.dispatchMouseEvent`）对 `#/graph` 模拟「按下→多次移动→松开→松开后多余移动（复现延迟更新）」，**ERRORS_CAPTURED:0**，图谱正常渲染 20 个节点。另注：CDP 合成 wheel 事件报 `Unable to preventDefault inside passive event listener`（3 条），属 headless 合成事件被当作 passive 的测试产物，非本次崩溃、亦不崩溃应用；真实浏览器 React `onWheel` 的 `preventDefault` 正常。

**坑/经验**：React 的 `setState(fn)` 更新函数可能在事件处理返回之后才执行，故更新函数内**禁止读取会被其他事件（如 pointerup）置空的 ref**；凡需读取可变 ref 的值，应先用局部 `const` 捕获快照再放进更新函数。此模式适用于本项目所有面板的平移/拖拽交互。
