## 十五·E4 排序交互修复：整体替换 → 逐行替换
- **用户反馈**：① 点 ▲▼ 一次没反应、反而"全选列"，再点才排序；② 没选中的列也跟着变。
- **根因①**：sortTable 用 `insertContentAt({from,to}, 新table, {updateSelection:false})` **整体重建 table 节点**——TableKit 表格的 colgroup（列宽）信息丢失、selection 在重建后被 ProseMirror 映射到奇怪位置（表现=触发列全选/第一次点击无效）。
- **修复①**：改为**逐行 `tr.replaceWith(rowPos, rowPos+rowNodeSize, schema.nodeFromJSON(buildTableRowJSON(...)))`**——只替换每行 cell 内容，table 节点/colgroup/选区全部保留，一次点击立即生效。新增 `tableSort.ts#buildTableRowJSON`（单行 JSON），组件不再用 buildTableNodeFromRows（保留导出但组件停用）。
- **②"没选中的列也变"= 标准排序行为**（Excel/Notion/Obsidian 同款：按列排序=整行随排序列移动，保持行内数据对应；只排单列会拆散行的对应关系）→ 向用户解释，不实现"单列排序"。
- **验证**：tsc 0；tableSort 8/8；全量 817 passed / 0 failed（基线 Path2D 除外）；build 成功。

## 十六·E4 排序严重 bug 修复：逐行替换 → 单次替换整表（保留原行 JSON）
- **用户反馈**：每点一次 ▲/▼ 表格行数增多、光标跳出表格、行与行断裂。
- **根因**：上一版"逐行 replaceWith"在**同一 transaction 上多次替换**——新行与旧行 nodeSize 不一致时，后续行 pos 全部错位（旧坐标未 map），导致内容插到错误位置 → 增行/断裂。且行重建丢失 cell attrs/内部格式。
- **修复（三版定案）**：`sortTable` 改为——① `collectTableRows` 取文本 → ② `sortRowOrder`（新纯函数，返回行索引序，表头 0 保持）→ ③ `collectTableRowJSONs`（新纯函数，`rowNode.toJSON()` 保留每行 cell attrs/格式）→ ④ 按新行序重组 + `table.toJSON()` 保留 table attrs → `schema.nodeFromJSON` 重建 → **单次 `tr.replaceWith(tableStart, tableStart+tableNode.nodeSize, newTable)`**。行数恒等于原行数，selection 由 ProseMirror 自动映射，cell 格式不丢。
- **坑**：同一 tr 多次 replaceWith 必须 map 坐标（或避免）；rowJSONs 用 `rowNode.toJSON()` 而非重包 {type,content}（后者丢 row attrs）。
- **验证**：tableSort 11/11（新增 sortRowOrder 索引序/一致性/rowJSON 保留 3 用例）；tsc 0；全量 820 passed / 0 failed（基线 Path2D 除外）；build 成功。

## 二十五·用户质询"报告有、界面没有"的落差根因（Slash 命令）
- **用户疑问**：报告 Slash 13 条里「参考文献模板」在界面哪打开、Slash 命令是什么。
- **Slash 命令是什么**：Tiptap WYSIWYG 编辑器的**行内斜杠命令面板**——在空行行首或空格后输入 `/` 弹出 13 条命令列表，可输入过滤 + ↑↓ 选择 + Enter/点击插入；`/link-template`（参考文献模板）即插入 `## 参考文献\n- [[]]\n- [[]]\n- [[]]`。**无按钮、无菜单项**，纯键盘触发，故"界面看不到"。
- **唯一真落点**：`features/editor/extensions/SlashCommand.ts`（createSlashCommands 13 条）+ `SlashCommandPopup.tsx`（弹层）+ `useTiptapExtensions.ts:149` 注册 + `TiptapEditor.tsx:727` 渲染。Aurora EditorPanel→EditorLayout→wysiwyg 模式渲染 TiptapEditor → **已接通**。
- **报告-界面落差根因（方法论）**：报告方法是「代码遍历盘点」(§二十四)，把**隐藏型能力**（Slash 键盘触发 / 右键菜单 27 项 / 快捷键）一律计为功能点；但这些在界面无可见入口，故"报告有、界面无"。这是盘点法的固有偏差，非 bug，但应在报告标注"可发现性=隐藏/交互触发"。
- **真 bug（新发现）**：`SlashCommandPopup.tsx:122` 触发正则 `(^|\s)\/([A-Za-z0-9-]*)$` **仅 ASCII**，中文用户打 `/参考文献` 不会弹面板（必须打 `/link` 或 `/link-template` 英文）；而 `scoreCommand` 却支持中文 label/keywords 过滤——自相矛盾。**建议**：正则放开为非空白字符 `(\S|$)` 类，或至少让 `/` 后中文也能唤起面板（中文用户直觉入口）。
- **模式依赖**：Slash 仅在 WYSIWYG（所见即所得）生效；源码模式用 CodeMirror，无 Slash。默认 wysiwyg，但若用户在源码模式也看不到属预期。
