## 日记编辑器双工具栏 / "旧版本编辑器" 修复（本回合）
- 用户反馈两个真问题：① 日记编辑区用的是"旧版本编辑器"；② 编辑器自带格式工具栏，日记界面又挂一个，两个冲突。
- **根因**：`DiaryPanel` 挂真实 `TiptapEditor`，而 `TiptapEditor` 内部无条件渲染内置 `WysiwygToolbar`（`EditorWysiwygToolbarSlot`→class `wysiwyg-toolbar`）+ 内置状态栏（`EditorStatusBarSlot`）；日记又单独挂 `DiaryFormatToolbar`。`diary.css` 本想隐藏内置栏，但规则写成 `.tiptap-editor-toolbar{display:none}`——**该类名根本不存在**（grep 全仓仅此一处死规则），故隐藏失效，内置旧式工具栏与日记轻量栏同时出现，整片编辑区看起来像"旧编辑器"。
- **修法（单一数据源·非脆弱 CSS）**：给 `TiptapEditor` 加 `showToolbar?` / `showStatusBar?` 两个 opt-out prop（默认 `true`，主编辑器行为不变、app 全范围安全）；`DiaryPanel` 两处挂载 `TiptapEditor` 传 `showToolbar={false}` + `showStatusBar={false}`，关闭内置 WYSIWYG 工具栏与状态栏，日记只保留自身 `DiaryFormatToolbar` 这**一个**格式栏。删 `diary.css` 死规则 `.dv2-editor-block .tiptap-editor-toolbar{display:none}`；同步修正 `DiaryFormatToolbar.tsx` 头部注释。
- **验证**：tsc=0；日记 6/6、aurora 85/85、features/editor 138/138 全绿，零回归（IndexedDB/Dexie 警告为 jsdom 良性缺失）。设计文档 `09-diary-panel.md` 合并块补「单一格式栏铁律」说明。待 dev 5174 肉眼验收（编辑区仅一个轻量格式栏、无双栏冲突、编辑器视觉与日记新设计一致）。。

## 日记 vs 主编辑器 配色不一致（根因+修法）
- 用户问「为什么日记编辑界面和主编辑器编辑界面颜色不一样」。
- **根因**：主编辑器与日记**挂载同一个 `TiptapEditor`**，其书写区背景由 `var(--editor-bg)` 驱动（`TiptapEditor.tsx:656`）。主编辑器靠 `editor.css:16-25` 的 `.aurora-editor { --editor-bg: var(--mc-bg-content); ... }` 作用域重映射把旧变量改写成 Aurora token（书写区=#101218 中性深灰）；日记挂在 `.dv2-root`，**不在 `.aurora-editor` 作用域**，故 `--editor-bg` 回落 `src/styles/base.css` 全局旧默认值 `#0f172a`（旧石板蓝）→ 与主编辑器色相不同。文字色一致（diary.css 强制 `.ProseMirror{color:var(--mc-text-primary)}`）。另日记把编辑器包在浮起卡片 `.dv2-editor-block`(bg `--mc-bg-elevated` #151821+边框)，主编辑器是齐平平面，框架观感也不同。
- **修法**：在 `diary.css` 的 `.dv2-editor-block` 作用域补与主编辑器**完全相同**的 `--editor-*` 重映射（`--editor-bg:var(--mc-bg-content)` 等 8 项）。现日记书写区背景=#101218，与主编辑器一致。卡片背景 `--mc-bg-elevated` 按用户选择**保留**（用户选"保留浮起卡片"）。
- **验证**：日记 6/6 全绿，零回归。纯 CSS 改动。
