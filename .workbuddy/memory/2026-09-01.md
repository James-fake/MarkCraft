## 白板子视图隐藏底层卡片·纠错（2026-09-01）

- 用户反馈：上一条"隐藏 tldraw 内容层"**未生效**——切到子视图后画布里的卡片内容仍在。
- **根因（关键认知错误）**：底层引擎实际是 **Excalidraw**（`@excalidraw/excalidraw` ^0.17.6），**不是 tldraw**。上一条用的 `.tl-canvas`/`.tl-ui` 是 tldraw 类名，在 Excalidraw DOM 中根本不存在 → 选择器零命中。
- Excalidraw DOM 真相（已核 node_modules 0.17 源码）：背景在 `.excalidraw` 根 div 的 CSS 背景（`--default-bg-color` 暗 `#121212` / 亮 `#ffffff`，或场景 `viewBackgroundColor`），图形画在子元素 `.excalidraw__canvas`（interactive + static 两个透明 canvas）上；引擎另叠加 HTML 富卡片浮层 `[data-card-overlay]`。故只需隐藏后两者即可保留同色底色。
- **落地（修正 canvas.css）**：删除错误的 `.tl-canvas`/`.tl-ui` 规则，改为
  `.aurora-canvas__viewport--behind .excalidraw__canvas, .aurora-canvas__viewport--behind [data-card-overlay] { opacity: 0 !important; }`
  ——隐藏 Excalidraw 图形层与富卡片浮层，`.excalidraw` 根背景保留 → 子视图背景与画布视图底色完全一致。

## 白板空态引导误弹修复（2026-09-01 续）

用户反馈：进入白板功能界面**每次都弹出**「空白画布」空态引导，即便画布已有卡片/标签等内容。

### 白板控制台告警清理（2026-09-01 续）

- **现象**：白板界面浏览器控制台三连告警：(1) `Can't call setState on a component that is not yet mounted`（来自 Excalidraw `App`/`InitializeApp`）；(2) `Permissions policy violation: unload is not allowed in this document`（Excalidraw `App.tsx:4806` 注册 `unload` 监听，第三方包内部，良性、无法在本仓 patch）；(3) `apple-mobile-web-app-capable is deprecated`（来自 `index.html:9`）。
- **根因 (1)**：`ExcalidrawCanvas.handleAPI` 是 `excalidrawAPI` 回调，在 Excalidraw 初始化期被同步调用，内部立即 `engine.loadDocument()` → `api.updateScene()` → 触发 Excalidraw 内部 `App` 的 `setState`（此时 App 尚未挂载完）→ 该告警。
- **改动 (1)**：把 `engine.loadDocument()` 与 `onReady` 一起推迟到 `requestAnimationFrame`（`ExcalidrawCanvas.tsx` `handleAPI`）。下帧时 Excalidraw `App` 已挂载，写入场景安全、告警消除；且 `onReady` 与 loadDocument 同帧，避免「引擎就绪但场景为空」的瞬时空态闪现。`attach(api)` 与 DEV 下 `window.__*` 暴露仍同步执行（无害）。
- **改动 (3)**：`index.html:9` `apple-mobile-web-app-capable` → `mobile-web-app-capable`（iOS 15.4+ 通用，消掉弃用告警；`status-bar-style`/`title` 两条 `apple-` meta 未弃用，保留）。
- **告警 (2)**：Excalidraw 自带 `unload` 监听触发，不在本仓代码内，属 Chrome 干预告警、不影响功能；不强行 patch node_modules（会被重装覆盖），归为第三方良性噪声。
- **验证**：`tsc --noEmit`=0。
- 待用户 5174 目测：白板控制台不再有 setState 告警与 apple-meta 弃用告警；(2) 的 unload 干预告警因属 Excalidraw 包内仍可能出现，属预期良性。

- **改动**：`CanvasPanel.tsx` 新增 `guideSkipped` state（默认 false）；引导显示条件加 `&& !guideSkipped`；`locked = isCanvasEmpty && !guideSkipped`；卡片底部新增「跳过，直接开始」文字按钮（`setGuideSkipped(true)`，弱强调、hover 变 accent）。`canvas.css` 新增 `.aurora-canvas__empty-skip`（卡片内 `align-self:stretch` + `justify-content:flex-end` 实现右下角靠右，纯文字无边框）。设计文档 `05-canvas-panel.md` §4.1 同步（锁定公式、解除锁定的两条路径）。
- **验证**：`tsc --noEmit`=0；`vitest run src/aurora/panels/canvas` 7/7 全绿（注：测试环境 jsdom 无 IndexedDB，Dexie MissingAPIError 为良性噪声，不影响断言通过；此前一次 `> /tmp` 重定向因该路径在本机不存在而误报 exit 1，重跑确认 EXIT=0）。
