## 白板工具切换 bug：点橡皮后再点其它工具切不回去（2026-09-02）

- **现象**：点「橡皮」工具后，再点底部工具栏的其它工具（选择/画笔/矩形…）切换不过去，工具被弹回橡皮。
- **根因（引擎工具态回写竞态）**：`CanvasEngine.setCurrentTool(id)` 同步把 `currentToolAtom` 设为目标工具并 `emit('session')`（dock 立即高亮新工具），但 `api.setActiveTool({type})` 经 Excalidraw 的 `this.setState` **异步**生效。橡皮→其它工具时 Excalidraw 需先退出 eraser 态，onChange→`syncFromScene` 在 `setActiveTool` 生效前读到仍是旧原生工具(`eraser`)，遂把 `currentToolAtom` 回写回 `eraser`，覆盖掉工具栏刚切的目标工具 → 表现为「切不回去」。（dock 本身 z-index:50 高于橡皮覆盖层 z-index:6，覆盖层不挡点击；`EXCALIDRAW_UI_OPTIONS` 只禁 canvasActions 未禁任何工具，故 `setActiveTool` 不静默 return——均排除。）
- **改动**：`CanvasEngine.ts`
  - 新增 `private toolSetAt = 0` 字段（响应式状态区）。
  - `setCurrentTool`：`currentToolAtom.set(...)` 后记录 `this.toolSetAt = Date.now()`。
  - `syncFromScene` 工具回写段：加 `toolJustSwitched = Date.now() - this.toolSetAt < 600`，窗口内**跳过** Excalidraw 旧工具回写（以 `currentToolAtom` 为权威）；窗口过后恢复正常回写（键盘快捷键仍同步 dock 高亮）。初始加载 `toolSetAt=0` 不受影响。
- **验证**：`tsc --noEmit`=0；`vitest run src/aurora/panels/canvas` 7/7 全绿。
- 待用户 5174 目测：点橡皮→点选择/画笔/矩形等→工具正常切换；dock 高亮跟随；橡皮擦覆盖层在切走后正确卸载。

## 白板检视「颜色按钮切不动便签颜色」bug 修复（2026-09-02）

- **现象**：点击便签→右侧检视「属性」自动打开后，点「颜色」色块切换便签颜色无反应（画布卡片颜色条不变、色块高亮也不切）。
- **根因（颜色值体系不统一 · D4 单一数据源缺失）**：渲染侧 `getColorDef(hex)` 只在 `CARD_COLORS_V2`（canvasTheme）的 `from` 字段里按 `c.from.toLowerCase()===hex` 匹配，匹配不到就 fallback 成 `CARD_COLORS_V2[0]`（靛蓝 `#6366F1`）。而检视面板 `CanvasInspectorPanel` 的 `COLORS` 是**另一套旧浅色 hex**（`#FDE68A/#86EFAC/...`），与 `CARD_COLORS_V2` 完全对不上 → 点任何色块都 fallback 成同一靛蓝，表现「切不动」。附带：`setShapes` 的重渲染签名只含 `id/text/pinned/isLocked`，**不含 color/fontSize**，改色时 `selected` 引用不刷新、色块高亮不跟随；高亮比较 `s.color===c` 大小写敏感；新建便签默认色（`addQuickNote '#FDE68A'`、文件便签 `'#E6F1FB'`、RecTab `'#C4B5FD'`）也都不在板内，初始即 fallback。
- **改动（统一到 CARD_COLORS_V2 单一数据源）**：
  - `CanvasInspectorPanel.tsx`：导入 `CARD_COLORS_LEGACY`（= `CARD_COLORS_V2.map(c=>c.from)`），`const COLORS = CARD_COLORS_LEGACY` 替代硬编码旧 hex；`setShapes` 签名加 `color/fontSize`（改色/字号即刷新 `selected`）；色块高亮比较改 `(s.color??'').toLowerCase()===c.toLowerCase()` 防大小写失配；RecTab 推荐卡片默认色 `'#C4B5FD'`→`'#8B5CF6'`（板内紫罗兰）。
  - `CanvasPanel.tsx`：`addQuickNote` 默认色 `'#FDE68A'`→`'#F59E0B'`（板内琥珀）；文件便签默认色 `'#E6F1FB'`→`'#06B6D4'`（板内青蓝）。
- **边界**：历史已存旧 hex 卡片仍会 fallback（次要数据兼容问题，不在本次范围）；本次保证新建/改色都落在 `CARD_COLORS_V2` 内、渲染可识别、检视高亮正确。
- **验证**：`tsc --noEmit`=0；`vitest run src/aurora/panels/canvas` 7/7 全绿。

## 搜索顶栏「按钮偏左」Bug 修复（2026-09-02·用户反馈「什么都没变、按钮全偏左」）

- **现象**：上一版「模式外置 + 右侧托盘」结构代码已落盘（`kb-searchpanel-top` 含 field + modes + actions，field `flex:1`、modes/actions `flex-shrink:0`），但用户在宽面板/全屏下看到的仍是「所有按钮堆在左边」。
- **真正根因（flex 布局，非缓存/级联）**：`.kb-searchpanel-field` 同时设了 `flex:1` 和 `max-width:640px`。`flex:1` 让它最多长到 640px 即停；而右侧 `modes`/`actions` 是 `flex-shrink:0`（不会增长去吃剩余空间）。结果：窗口一宽，field 停在 640px，modes+actions 紧贴其后，**剩余空白全留在最右边** → 视觉上整排按钮偏左（未贴右）。
- **修复（一行）**：给 `.kb-searchpanel-modes` 加 `margin-left:auto`，把「模式 + 操作组」整体推到顶栏最右；搜索框仍留在左侧、保持 ≤640px 合理宽度。无需改结构，纯 CSS。
- **验证**：`tsc --noEmit`=0；`vitest run KbSearchPanel.test` = 3/3 全绿。
- **经验沉淀**：flex 顶栏想「左输入框 + 右操作」且输入框有 max-width 时，右侧组必须用 `margin-left:auto` 推右，不能只靠输入框 `flex:1`（max-width 会吃掉增长）。

## 编辑器右栏检查器 Tab 切换失效修复（2026-09-02）

- **现象**：编辑器界面右栏检查器（大纲 / 脚注 / 块级反链 / 辅助 四个 Tab），点击「脚注 / 块级反链 / 辅助」进不去——Tab 高亮不动、内容始终停在大纲。
- **根因（双错叠加）**：
  1. `EditorPanel` 把 `RightSidebar` 接成**受控模式**但写死 `activeTab="outline"` 且 `onTabChange={() => {}}`（空操作）。点非大纲 Tab 时 `selectTab` 只调空操作、内部 `tab` 不更新，`currentTab = activeTab ?? tab` 永远 `'outline'` → 高亮与内容全卡大纲。
  2. `RightSidebar` 的内容渲染区（180–193 行）用的是**内部 `tab` 状态**而非 `currentTab`；即便 `activeTab` 被正确透传，内容仍渲染内部 `tab`（受控模式下永不更新）→ 永远显示大纲。
- **改动（两处配合 · 单一数据源）**：
  - `RightSidebar.tsx`：导出 `InspectorTab` 类型（`export type InspectorTab`）；内容渲染的 4 处 `tab ===` 全部改为 `currentTab ===`（大纲/脚注/块级反链/辅助），与 Tab 高亮同源。
  - `EditorPanel.tsx`：import `InspectorTab`；新增 `const [rightTab, setRightTab] = useState<InspectorTab>('outline')`；`RightSidebar` 由 `activeTab="outline" onTabChange={() => {}}` 改为 `activeTab={rightTab} onTabChange={setRightTab}`——受控态真正受状态驱动。
- **验证**：`tsc --noEmit`=0；`EditorPanel.smoke` 6/6 全绿（新增 test 6 回归：鼠标靠右缘滑入检查器后，点「脚注」→ `.aurora-footnotes` 渲染 + aria-selected=true；点「块级反链」→ `.aurora-backlinks`；点「辅助」→ `.aurora-aid`；IndexedDB 告警 jsdom 良性）。
- **待用户 5174 目测**：编辑一篇笔记 → 右缘滑入检查器 → 点「脚注 / 块级反链 / 辅助」均能切进对应面板、Tab 高亮跟随；钉住常驻时同样可切换。
