## 修复：WYSIWYG 编辑区字号异常变大

## 优化：编辑区左右边缘 hoverzone 滑出面板防误触（hover-intent 延迟）
- **用户澄清（关键纠正）**：上一轮「识别展开过快」误判为搜索框滚动手势，实际指的是**编辑区左右边缘 hoverzone 触发文件树/检查器滑出**的速度——鼠标一靠到边缘（7px hoverzone）立即 `onMouseEnter → setXHover(true)` 弹出浮层，极易误触。
- **定位**（`src/aurora/panels/editor/EditorPanel.tsx`）：左 `.aurora-editor__hoverzone--left`（滑入 FileTree 浮层）、右 `.aurora-editor__hoverzone--right`（滑入检查器浮层）的 `onMouseEnter` 同步触发；overlay 是 hoverzone 子元素（`position:absolute` 在其内），展开后鼠标在列表上不误收（此点不变）。
- **改动**：引入 **hover-intent 停留延迟**——进入边缘需停留约 `HOVER_INTENT_MS = 220` 才滑出；快速掠过/误触在 220ms 到期前 `onMouseLeave` 清除定时器而取消，不再一碰即弹；离开立即收起；已钉住（pinned）时无需 hover、离开不收起。
  - 新增 `leftHoverTimer`/`rightHoverTimer`（`useRef<number|null>`）+ `openLeftIntent/openRightIntent`（setTimeout 延迟置 true）+ `closeLeftIntent/closeRightIntent`（清除 timer + 未 pin 则收起）；卸载 `useEffect` 清理挂起定时器防泄漏。
  - JSX 左/右 hoverzone 的 `onMouseEnter/onMouseLeave` 由内联 `setXHover` 改为 `openXIntent/closeXIntent`。
- **测试同步**（`EditorPanel.smoke.test.tsx` 第 6 项）：`mouseEnter` 后立即断言浮层渲染已不成立（延迟 220ms），改为 `vi.useFakeTimers()` + `act(() => vi.advanceTimersByTime(260))` 推进定时器使浮层真正渲染，用 `try/finally` 确保 `vi.useRealTimers()` 收口。
- **验证**：`tsc --noEmit` = 0；`vitest run src/aurora/panels/editor/EditorPanel.smoke.test.tsx` = **6/6 passed**（沙箱本次可收集；IndexedDB missing 为 jsdom 良性告警）。
