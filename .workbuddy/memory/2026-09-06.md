## AuroraSelect（文字滚轮下拉）改为 hover 自动展开（对齐数字滚轮）
- **需求**：文字选择的滚轮鼓要与数字滚轮鼓（ScrollNumberInput）一致——鼠标**触碰触发器即自动展开**，而非点击才开。
- **改法（`src/components/ui/AuroraSelect.tsx`）**，复刻 ScrollNumberInput 的 hover 模式：
  - 新增 `hoverTimer` ref + `cancelClose()` / `scheduleClose()`（移出后 **160ms** 收起）/ `onTriggerEnter()`（触碰即开：cancelClose 先行，未开则量 rect + 重置 pending 再 `setOpen(true)`）。
  - 触发器 button 挂 `onMouseEnter={onTriggerEnter}` `onMouseLeave={scheduleClose}`；滚轮浮层（portal 到 body）挂 `onMouseEnter={cancelClose}` `onMouseLeave={scheduleClose}`——保证鼠标能跨过触发器与浮层间 6px 间隙移入滚轮不误收。
  - 点击开关（`toggle`）保留（开→再点关）；卸载 cleanup 同时清 `hoverTimer`。
- **注意点**：trigger 在 popover 的 mouseenter 里**先 cancelClose 再判断 open**（而非 open 即 return），避免「从浮层回移触发器途中被 popover 的 scheduleClose 收掉」的竞态。
- **验证**：`tsc --noEmit`=0；Settings smoke + PlatformPublishPanel 32/32 全绿（点击打开路径不受影响）。
- **用户目测点**：任何文字下拉（设置各 Section / 博客 / KB 等）鼠标移上即弹出滚轮鼓；移出约 0.16s 收起；期间鼠标移进滚轮可停留滚动/点选。

## 白板左右边缘 hoverzone 防误触（对齐编辑器 v7 手感）
- **需求**：白板界面左右两侧列表（左「浏览」/右「检视」）鼠标移到边缘就立即展开，一碰就弹、易误触。
- **根因**：`CanvasPanel.tsx` hoverzone 的 `onMouseEnter` 同步 `setLeftHover/setRightHover(true)`，无任何停留门槛。
- **改法（`CanvasPanel.tsx` 单文件）**，一字不差移植编辑器已认可的 hover-intent 块：
  - `HOVER_INTENT_MS=220`（停留才展开）+ `HOVER_CLOSE_DELAY_MS=180`（收起延迟打断「收→触发条重现→再弹」抖动循环）。
  - 4 个 timer ref（left/right × open/close）+ 5 组 handler：`cancel*Close` / `open*Intent`（locked|pinned 短路、cancel close、220ms 后开）/ `schedule*Close`（locked|pinned 短路、180ms 后收）/ `close*Intent`（清 open timer + schedule）。卸载 cleanup 全清。
  - **locked（空画布引导锁定）短路**：locked 时整组 hover 停用（原代码在 handler 内 `if(locked)return`，现并入 open/schedule 依赖，语义不变）。
  - hoverzone `onMouseEnter/onMouseLeave` 改接 intent handlers；左右 overlay（绝对定位溢出 7px hoverzone 的 280px 浮层）均加 `onMouseEnter={cancel*Close}` / `onMouseLeave={schedule*Close}` 双保险，保证跨入浮层细读不误收。
  - `closeLeft/closeRight`（原清 hover+pinned 的按钮语义，右另清 selectionOpen）保留不变；`rightShown = pinned|hover|selectionOpen` 三态互不干扰——hover 只收自己贡献，选区展开不被动。
- **验证**：`tsc --noEmit`=0；CanvasPanel + CanvasSidebarPanel smoke 7/7 全绿（两 smoke 均不依赖 hoverzone 同步展开）。
- **用户目测点**：轻扫白板左右边缘不再立即弹出；有意停留约 0.22s 才滑入；停留中移开取消；移入浮层可安心停留；完全移开约 0.18s 收起且不再抖动循环。手感偏差可调 `HOVER_INTENT_MS`（180–300）。
