**根因（CDP + 位图取证，修正了方案文档原判）**：

**验证**：CDP 实测 filter=none 后屏幕采样 = (13,15,21) 精确达标；全图亮像素 1981/2432 → 5/2432（剩文字反锯齿）；tsc=0、vite build 退出 0。截图：`.workbuddy/tmp/shots/plan3-canvas{,-fixed}.png`。

**方法论**：PIL 全图网格采样发现 81% 亮像素 → 单点位图暗/屏幕亮矛盾 → elementsFromPoint 排除法 → 定位 static canvas 的 computed filter → 位图算术验证（invert(0.93) 精确吻合）→ 引擎配色方向判断（浅色笔迹证明按暗色直出创作）→ filter:none 修复。headless 陈旧帧、pointer-events:none 元素不入 elementsFromPoint 是两个关键坑。
