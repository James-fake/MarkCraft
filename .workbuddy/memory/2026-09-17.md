## 交互动效审查：退场（收回）缺失（用户报「收回没有动画，不够 Apple」）

### 结论（根因）
浮层族全部是 `{open && createPortal(...)}` / `{isOpen && …}` 条件渲染 → **关闭即瞬时卸载**，
CSS 只有 `-in` 关键帧、没有 `-out`，JS 也没有「先播退场再卸载」的相位机。
**不是动画不够多，是对称性缺口**：入场 180ms 播得很好，收场 0ms 硬切。

### 本仓已有三个正确范式（改造以此为单源）
- `components/ui/Modal.tsx:36,67–82,145` — `phase: open→exiting→closed` + `data-exiting` + `MODAL_EXIT_MS=180`。
- `components/ui/ToastProvider.tsx:135–136` — `exiting: true` + `TOAST_EXIT_MS` 后 filter。
- `shell.css:432–445` + `Sidebar.tsx` — 分组折叠 `grid-template-rows: 0fr↔1fr` + opacity 双向过渡。

### 缺口清单（6 类 / 16 处，全为「有入场无退场」）
菜单栏 `MenuBar.tsx:349`；工具栏下拉 ×4（`ListDropdown:70` / `MoreDropdown:82` / `SourceHeadingDropdown:126` /
`WysiwygHeadingDropdown:56`）；右键菜单 ×5（`CanvasContextMenu:99` / `CanvasDock:278` / `CanvasInspectorPanel:87` /
`FileTree:560,584` / `AuroraOutline:328`）；滚轮 ×6（`AuroraSelect:161` 等，`components.css:780`）；
面板悬浮侧栏 ×3（`CanvasPanel:606,727` / `EditorPanel:733` / `GraphPanel:1114`，`canvas|editor|graph.css` `aurora-overlay-in`）；
Dock 浮菜单（`canvas.css:1692`）。

### 方案（写在 `artifacts/DESIGNBRIEF-MOTION-EXIT-01.md`）
- 新增共享原语 `hooks/usePresence.ts`：把 Modal 的相位机抽出，返回 `{mounted, exiting}`；
  `open=true` 立即回 `open`（**可中断**，退场中途重开不跳变）。
- CSS 补镜像 `-out` 关键帧（**同路径反演**）+ `[data-exiting='true']` + `pointer-events:none`；
  **退场用 `--mc-ease-in`（加速离场 = Apple「出更快」）**：浮层 100ms（`--mc-dur-micro`），面板浮层 180ms（`--mc-dur-fast`，与 Modal 入 420→出 180 同比例）。
- `EXIT_MS` 必须与 CSS 动画时长**逐字对齐**（沿用 Modal 既有约定）。
- 契约测试：`-in`/`-out` 成对断言 + 退场规则必含 `pointer-events:none`/`--mc-ease-in` + 无 `scale(0)` + `usePresence` 单测。

## 二级栏同源化：三面板 subbar 统一 52px

**用户指令**：把其他面板同步到 52px subbar。**但真正的问题不是"数字不一样"。**

### 诊断：同一个设计量在 3 个文件里各写一份

| 白板 | `.aurora-ctop` | 46px + compact 42px | **42** | 52 |

  于是「知识库 52 / 其余 42」是常态，跨视图切换二级栏跳 10px。

### ⚠️ 本轮三个方法论级教训（已升进 MEMORY.md 铁律）
1. **「零 import」≠「不进包」**：`Input.tsx` 零直接导入，却因 `index.ts` 桶里有 `export { Input }`，
   任何 `from '.../components/ui'` 都会把整个桶图带进模块图（dev 不做 tree-shaking）→
   `ui.css` 照样下发（真机 `style[data-vite-dev-id]` 取证到 `.../components/ui/ui.css`）。
   **判死代码必须看依赖图可达性，不能只看 import 计数。**
2. **判死必须先排除「模板拼接」**：`Button.tsx` 写的是 `` `aurora-btn--${size}` ``、`Modal.tsx` 是 `` `aurora-modal--${size}` ``、
   `ToastProvider.tsx` 是 `` `aurora-toast--${t.kind}` `` → 字面量 `aurora-btn--sm` 从不出现，纯字面量扫描会**误判活类为死**。
   扫描器已升级为三档（A 高危 / B 疑似动态 / C 仅测试引用），且**前缀抽取只取最后一个空白分隔词**
   （`` `aurora-modal aurora-modal--${size}` `` 若整段当前缀 → 含空格 → 永不命中 → 假阳性进 A 档）。
3. **守卫断言自身的边界也要证伪**：第一版代码锚点用了带前导点的 `\.mc-tooltip` → 漏检 `className="mc-tooltip"`；
   尾部用 `\b` → 漏检 `aurora-tooltip__arrow`（`_` 是词字符）；完全不管尾部 → 误伤 `.aurora-tooltips`。
