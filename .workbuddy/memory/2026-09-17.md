## 交互动效审查：退场（收回）缺失（用户报「收回没有动画，不够 Apple」）

### 结论（根因）
浮层族全部是 `{open && createPortal(...)}` / `{isOpen && …}` 条件渲染 → **关闭即瞬时卸载**，
CSS 只有 `-in` 关键帧、没有 `-out`，JS 也没有「先播退场再卸载」的相位机。
**不是动画不够多，是对称性缺口**：入场 180ms 播得很好，收场 0ms 硬切。

### 本仓已有三个正确范式（改造以此为单源）
- `components/ui/Modal.tsx:36,67–82,145` — `phase: open→exiting→closed` + `data-exiting` + `MODAL_EXIT_MS=180`。
- `components/ui/ToastProvider.tsx:135–136` — `exiting: true` + `TOAST_EXIT_MS` 后 filter。
- `shell.css:432–445` + `Sidebar.tsx` — 分组折叠 `grid-template-rows: 0fr↔1fr` + opacity 双向过渡。

### 缺口清单（6 类 / 16 处，全为「有入场无退场」）
菜单栏 `MenuBar.tsx:349`；工具栏下拉 ×4（`ListDropdown:70` / `MoreDropdown:82` / `SourceHeadingDropdown:126` /
`WysiwygHeadingDropdown:56`）；右键菜单 ×5（`CanvasContextMenu:99` / `CanvasDock:278` / `CanvasInspectorPanel:87` /
`FileTree:560,584` / `AuroraOutline:328`）；滚轮 ×6（`AuroraSelect:161` 等，`components.css:780`）；
面板悬浮侧栏 ×3（`CanvasPanel:606,727` / `EditorPanel:733` / `GraphPanel:1114`，`canvas|editor|graph.css` `aurora-overlay-in`）；
Dock 浮菜单（`canvas.css:1692`）。

### 方案（写在 `artifacts/DESIGNBRIEF-MOTION-EXIT-01.md`）
- 新增共享原语 `hooks/usePresence.ts`：把 Modal 的相位机抽出，返回 `{mounted, exiting}`；
  `open=true` 立即回 `open`（**可中断**，退场中途重开不跳变）。
- CSS 补镜像 `-out` 关键帧（**同路径反演**）+ `[data-exiting='true']` + `pointer-events:none`；
  **退场用 `--mc-ease-in`（加速离场 = Apple「出更快」）**：浮层 100ms（`--mc-dur-micro`），面板浮层 180ms（`--mc-dur-fast`，与 Modal 入 420→出 180 同比例）。
- `EXIT_MS` 必须与 CSS 动画时长**逐字对齐**（沿用 Modal 既有约定）。
- 契约测试：`-in`/`-out` 成对断言 + 退场规则必含 `pointer-events:none`/`--mc-ease-in` + 无 `scale(0)` + `usePresence` 单测。

### 明确拒绝（不该动的地方，已记录）
命令面板（键盘 100+/天，已有 `commandPaletteNoAnim.test.ts` 守卫）；视图切换 `aurora-content-in`（09-11 已定稿）；
Toast/Modal（已对称）；**FileTree/Outline 展开收起**（高频导航 + VS Code 惯例，瞬时才对）；Tooltip hover-out（即时消失才正确）。

（ui/Tooltip 走 `mc-tooltip`）→ 死 CSS，建议清理或接线，勿先动画。

## 实施：退场动效收口（P0+P1 一次做完 · 用户拍板「按照你的计划优化」）

### 与方案的差异（三处，都要记住）
1. **原语位置改了**：方案写 `src/aurora/hooks/usePresence.ts`，实际落 **`src/components/ui/usePresence.ts`**。
   原因：`src/features/toolbar/*` 是逻辑层，守卫 `local/no-aurora-ui-import`（`.eslintrc.guard.cjs`）**禁止反向依赖 aurora UI**。
   `src/components/ui/` 是共享中性层（features 早已在此引 `AuroraSelect`/`ToastProvider`），放这里两侧都能向下引用。
2. **API 扩了一个**：`usePresenceValue(value, exitMs)` —— `{menu && …}` 型浮层在 `setMenu(null)` 那一刻就丢了坐标，
   必须用 `lastRef` **保留最后一份非空载荷**才能在退场窗口内继续渲染（否则菜单无法「缩回弹出处」）。
3. **覆盖面 16 → 18 处**：recon 补漏 —— 图谱面板的**导出下拉** `.aurora-graph__menu` 与**节点右键菜单** `.aurora-graph__ctx`
   此前**连入场都没有**（瞬时出现），与同族 ctxmenu 明显不同步，一并补齐进出双向。

### 落地清单
- 新增：`src/components/ui/usePresence.ts`（`usePhase` 内核 + 两包装 + `POPOVER_EXIT_MS=100`/`OVERLAY_EXIT_MS=180`）、
  `usePresence.test.ts`(10)、`src/aurora/styles/motionExit.test.ts`(53)、
  `artifacts/MOTION-EXIT-DEMO.html`（可交互前后对照）、探针 `probe-motion-exit.mjs` / `capture-open-state.mjs`。
- CSS 退场关键帧/规则：`components.css`(dropdown/menu/wheel)、`canvas.css`(overlay+right / dock-float / ctxmenu / cip-menu)、

  `tokens.css`(reduced-motion 名单补 12 个退场选择器)。
- TSX 18 处接相位机：`MenuBar`（抽出模块级 `MenuPop` 子组件 —— `MENUS.map` 里不能直接调 hook）、工具栏下拉 ×4、
  右键菜单 ×5、滚轮 ×3、面板浮层 ×3、Dock ×4、图谱 ×2。

### 三个坑（每个都值得写进铁律）
1. **reduced-motion 会「劫持」退场**：`tokens.css §11` 对 `.aurora-dropdown` 等一律 `animation-name: mc-rm-fade !important`，
   而 `mc-rm-fade` 是**淡入**。退场选择器若不逐个登记进 `mc-rm-fade-out` 名单，降级模式下退场 = 「淡入再消失」闪跳。已登记 12 个 + 断言守。
2. **`animation` 简写 vs `animation-name` 覆盖**：退场规则用简写 `animation: <name> <dur> <ease> forwards` 定时长；
   降级模式只覆盖 `animation-name`（`!important`），时长仍取简写值（100/180ms）→ 语义正确，无需额外处理。
3. **同文件多处 Edit 必须串行（本轮踩了两次）**：并行 Edit 到同一文件，后写覆盖先写、**静默丢改动**。
   症状是 `tsc` 报自相矛盾的组合（「变量声明未使用」+「找不到该名称」）。**改完必须 grep 核验**，不能只看 Edit 返回 success。
   实测丢了：`aurora-menu-out` 关键帧定义、`CanvasPanel`/`EditorPanel`/`AuroraSelect`/`CanvasDock`/`CanvasContextMenu` 的部分接入点。

### 验证
- 新增 63 例全绿；全仓 **1233 passed / 3 failed / 2 skipped**（3 项 = 既有预存 `commandWiring`/`KbPanel.smoke`/`blogCssRefs`）。`tsc` 干净。
- **3 项既有断言因本次改造失效，已按新契约加强（而非放宽）**：`MenuBar.smoke`×2、`GraphPanel.smoke`×1 ——
  从「关闭后立刻为 null」改为「先断言 `data-exiting='true'`（退场真在播）→ 再 `waitFor` 卸载」。
- **真机 CDP@9446**（Edge headless，page 内 rAF 采样 opacity/`data-exiting`/`pointer-events`）：
  菜单栏下拉 4 帧退场/3 帧中间值（`1→0.995→0.872→0.701`）；图谱导航浮层 11 帧/9 帧中间值（`0.993→…→0.726`）；

## 附：3 项「预存失败」清剿（同日续）

**结论：三项全是「测试契约跟不上真实实现演进」，无一是产品 Bug。** 全仓回到 **0 失败**。

### 顺带产出（非镀金，都是修这些测试时的必需品）
