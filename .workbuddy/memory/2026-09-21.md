## 菜单栏功能重复审计 + A/E 修复（用户指令「审计标题栏菜单重复」）

### 审计结论（7 菜单 · 45 命令项）
- **精确重复 = 0**（无同 id 重复、无同名标签重复）。
- **功能重叠 4 组**：
  - A（高）`navigation.quickSwitcher`（快速切换文件）与 `navigation.quickOpen`（快速打开）**皆按名称模糊打开文件**——quickSwitcher 名不副实（列全部文件非已开标签）。
  - B（中高）`navigation.globalSearch`（前往·全局搜索）与 `tools.crossKbSearch`（工具·跨知识库搜索）——单库模型下跨库 ⊂ 全局。
  - C（中）`file.openDailyNote`（打开今日笔记）与 `tools.diary`（日记面板）——相邻非重复。
  - D（中）`tools.openBlockBacklinks`（块反链）与 `tools.generateReverseMoc`（生成反向 MOC）——相邻非重复。
- **死项 / 降级（窗口菜单）**：`window.bringAllToFront` action 是字面空操作 `() => {}`；`window.minimize`→`window.blur()`、`window.zoom`→全屏切换（Web 降级）。
- **分类串味（非重复，但入口散落）**：`tools.*` 塞进 文件/前往、`editor.*` 塞进 工具、`settings.*` 塞进 帮助（命令命名空间与落点菜单不一致）。
