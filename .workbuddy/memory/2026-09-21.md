## 前往菜单加宽（用户指令「前往菜单按钮文字过长换行挤到一块，要求加宽菜单」）

### 根因（两层）
1. `.aurora-dropdown__item-label`（components.css）只有 `flex:1` **无 `white-space:nowrap`** → CJK 标签在任意字处断行，窄面板下折行挤叠。
2. `MenuBar.tsx` 的 pop 同时挂 `aurora-dropdown aurora-menubar__pop` 双类：components.css `.aurora-dropdown` 设 `min-width:180px; max-width:320px`，shell.css `.aurora-menubar__pop` 同为单类选择器 → **按加载序被 180 压窄**，写 264 也不生效（实测 popWidth=195）。

### 修复（`src/aurora/styles/shell.css`）
- 宽度规则升级双类 `.aurora-dropdown.aurora-menubar__pop`（特异性 0,2,0 压过 `.aurora-dropdown` 0,1,0）：`min-width:264px; max-width:400px`。
- 新增 `.aurora-menubar__pop .aurora-dropdown__item-label { white-space: nowrap; }`（后代选择器 0,2,0 已赢，无需双类）。

### 验证（CDP 探针 `.workbuddy/probe-menubar-width.mjs`，不入库）
- **探针两坑**：① `/json/version` 的 ws 是 **browser 级**端点，无页面执行上下文 → eval 恒 0；须用 `/json/list` 取 `type:'page'` 的页面级 ws + 显式 `Page.navigate`。② Node22 全局 WebSocket 是 EventTarget（`addEventListener`，无 `.on()`）。
- 终值：`popWidth=264`（264 下限生效）、9 项 `labelHeights` 全 20px、`ANY_WRAP=false`；截图确认单行铺开、快捷键右对齐。
- 回归：`tsc --noEmit` 干净；MenuBar.smoke 9/9；全量 vitest **112 文件 1493 passed/2 skipped/0 failed**（与基线一致）。

## 桌面端尺寸收敛（用户指令：全屏下页面/内容尺寸要像原生桌面软件）

### 范围拍板（AskUserQuestion）
- WYSIWYG 书写列 + 预览阅读列约束到 **舒适行宽 820px 并居中**；欢迎页已合规（max-width:920px）不改；**源码列保持满宽**（贴近 VS Code 代码编辑器惯例，长行横向滚动）。

### 根因
- 外壳 `.aurora-page` 满窗正确（桌面 app 占满窗口）；**真实 offender = 内容列无 max-width**：
  - WYSIWYG：`.tiptap-editor-content`（ProseMirror 文本块，真实 DOM，非 `.aurora-editor__wysiwyg` 等 legacy 死规则）无约束 → 全屏拉成 ~1830px 网页宽。
  - 预览：`.preview-container.markdown-preview` 是滚动容器，markdown 经 `container` ref 直接 innerHTML 注入为直接子元素（无内层 wrapper）→ 子块无列约束。

### 修复
- `src/styles/tiptap.css`：`.tiptap-editor-content` 加 `max-width:820px; margin:0 auto`（书写列居中，两侧留编辑器底色）。
- `src/styles/markdown.css`：`.preview-container.markdown-preview` 改 `display:flex; flex-direction:column; align-items:center`；`.markdown-preview > *` 加 `width:100%; max-width:820px`（文本块 820 居中）；`.markdown-preview > img, > .preview-image-container` 改 `width:auto`（图片保持自然宽并居中，不被拉伸）。

### 验证（CDP 探针 `.workbuddy/probe-fullscreen.mjs`，不入库）
- **探针坑**：沙箱 `http_proxy` 拦截 localhost:5174 → curl 502；Node22 全局 `fetch` 忽略 HTTP_PROXY（CDP `/json/list` 正常），但 Edge `Page.navigate` 须 `--proxy-server=direct://` 才不绕代理。dev server 须用 `exec node vite ...` 前台常驻（run_in_background），`&` 子进程随 shell 退出即死。
