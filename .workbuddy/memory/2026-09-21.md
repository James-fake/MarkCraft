## 前往菜单加宽（用户指令「前往菜单按钮文字过长换行挤到一块，要求加宽菜单」）

### 根因（两层）
1. `.aurora-dropdown__item-label`（components.css）只有 `flex:1` **无 `white-space:nowrap`** → CJK 标签在任意字处断行，窄面板下折行挤叠。
2. `MenuBar.tsx` 的 pop 同时挂 `aurora-dropdown aurora-menubar__pop` 双类：components.css `.aurora-dropdown` 设 `min-width:180px; max-width:320px`，shell.css `.aurora-menubar__pop` 同为单类选择器 → **按加载序被 180 压窄**，写 264 也不生效（实测 popWidth=195）。

### 修复（`src/aurora/styles/shell.css`）
- 宽度规则升级双类 `.aurora-dropdown.aurora-menubar__pop`（特异性 0,2,0 压过 `.aurora-dropdown` 0,1,0）：`min-width:264px; max-width:400px`。
- 新增 `.aurora-menubar__pop .aurora-dropdown__item-label { white-space: nowrap; }`（后代选择器 0,2,0 已赢，无需双类）。

### 验证（CDP 探针 `.workbuddy/probe-menubar-width.mjs`，不入库）
- **探针两坑**：① `/json/version` 的 ws 是 **browser 级**端点，无页面执行上下文 → eval 恒 0；须用 `/json/list` 取 `type:'page'` 的页面级 ws + 显式 `Page.navigate`。② Node22 全局 WebSocket 是 EventTarget（`addEventListener`，无 `.on()`）。
- 终值：`popWidth=264`（264 下限生效）、9 项 `labelHeights` 全 20px、`ANY_WRAP=false`；截图确认单行铺开、快捷键右对齐。
- 回归：`tsc --noEmit` 干净；MenuBar.smoke 9/9；全量 vitest **112 文件 1493 passed/2 skipped/0 failed**（与基线一致）。
