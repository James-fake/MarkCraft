## 白板优化：右栏展开时缩放控件避让（不再与检视浮层重叠）

报障：白板右下角缩放控件固定贴右缘（`right:16px`，z 50），右栏「检视」浮层（280px，z 7）展开时
被控件压住 —— 控件叠在浮层上面挡内容。

### 几何推导（关键：两个锚点不同缘）
- 缩放控件锚定 `.aurora-canvas__main`（`position:relative`），其右缘因**右 hoverzone（7px）**
  比 `.aurora-canvas__row` 右缘窄 7px；
- 右栏浮层锚定 row 右缘（`right:0`，宽 280px）⇒ 浮层左缘在 main 坐标 = 280+7 px 处；
- 保持 16px 视觉边距 ⇒ `right = 280 + 16 − 7 = 289px`（初版若直接写 296px 会多偏 7px）。

### 实现（单源 token 化，不造新魔数）
- `.aurora-canvas__overlay` 宽度由字面量 `280px` 改为 **全局 token `--mc-inspector-w`**
  （tokens.css 已有，壳层右 Inspector 同语义同宽）⇒ 改侧栏宽两处跟随；
- `.aurora-canvas__row` 新增局部几何变量 `--aurora-canvas-hoverzone-w: 7px`，hoverzone flex-basis /
  edge 宽度 / 避让位移三处共用（防漂移）；
- 新规则 `.aurora-zoom-controls--right-open { right: calc(var(--mc-inspector-w) + 16px - var(--aurora-canvas-hoverzone-w)) }`；
- 基础规则加 `transition: right var(--mc-dur-slow) var(--mc-ease-mac)`（与浮层滑入同档；
  reduced-motion 由 tokens.css 全局减半，自动降级）；
- `CanvasZoomControls` 加 `rightPanelOpen?: boolean` prop 切类；CanvasPanel 传
  `rightOverlay.mounted`（usePresence，**覆盖入场/展开/退场全程**，退场中浮层仍可见故保持避让）。
