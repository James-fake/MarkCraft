## 真机探针踩坑（P2-2 CDP，可复用 → probe-p22-editor.mjs 已入库）
- 🚨 **Vite 默认绑 localhost=IPv6 回环(::1)**，fetch 127.0.0.1「进程已起但连不上」⇒ 必须 `--host 127.0.0.1`。这是本轮探针假失败的头号原因。
- Edge spawn：bash 内联里反斜杠路径被吞（C:\Program → C:Program）⇒ 用正斜杠；加 `--remote-debugging-address=127.0.0.1`。
- 🚨 **FileStore 两阶段初始化会拿 IDB 整体覆盖 localStorage** ⇒ 新 profile 下「往 localStorage 种数据再 reload」不可靠（数据被清空）⇒ 探针改走真实 UI（点「新建笔记」按钮）造数据，更稳更真。
- 🚨 **所见即所得（TipTap）会规范化未闭合代码块** ⇒ 修改内容后 lint 错误自然消失 ⇒ lint 取证必须在任何键入之前；且用 `# 一级标题` + `### 三级标题`（TipTap input rule 转标题）制造「层级跳跃」warning 才能在所见即所得里稳定触发。
- 「未保存」态窗口 = 自动保存防抖 500ms ⇒ 键入后须 ≤120ms 内开始抓取，否则永远抓不到（以「已保存+字数增长」作补证）。
- PowerShell Start-Process 起的 vite/Edge 在本环境立即消失（沙箱拦截）⇒ 探针自持 spawn（成功模式）或外部手动启动；bash 后台 `&` 也会随调用结束被回收。
- bash 后台任务 `&` + run_in_background：vite 显示 ready 但调用结束进程即被杀 ⇒ 长驻服务要么探针自持 spawn，要么 PowerShell Start-Process（后者本环境不可用）。
