## ✅ M-1 直接深链 `#view=kb` 时知识库列表为空

**根因**：`KbManagePanel` 在挂载时 `getKbList()` 取**一次**；而内置「使用文档」知识库的播种是
**异步**完成、完成时间在面板挂载之后 → 列表永久停在空态（播种日志已打印「播种完成」，UI 仍 0 个）。

**修复**（`stores/kbStore.ts` + `aurora/panels/kb/KbManagePanel.tsx`）：
- 新增 `subscribeKbList(listener)`：列表写入时广播；订阅瞬间再补推一次当前值（覆盖「订阅发生在首次写入之后」）。
- 列表写入口收敛为 `writeKbList(list)` = 落盘 + 广播（`upsertListItem` / `removeListItem` 都走它）。
- 面板由「挂载取一次」改为订阅：`useEffect(() => subscribeKbList(setKbList), [])`。

**回归**：
- 单测：`KbManagePanel.smoke.test.tsx` 新增用例 —— 挂载时列表为空 → 随后 store 广播 → 面板必须自动跟上。
- E2E：`05-kb.spec.ts` 新增 —— **直接深链 `#view=kb`**（不经编辑器，复现原场景）必须显示内置知识库。

## ✅ L-1 新建笔记后立即刷新会丢数据

**根因（比报告初稿更严重）**：`fileService.saveState` 是 **300ms 防抖**（`SAVE_DEBOUNCE`）。
用户在防抖窗口内刷新 / 关闭标签，**定时器根本不会触发** —— 这次变更**连写都没开始**，
而不是「写入未完成」。原报告写的「写入异步」只是次要因素。

**修复**（`services/fileService.ts`）：
- 新增 `pendingState` 暂存待写快照 + `flushPendingSave()`（取消防抖并立即落盘）。
- 在 **pagehide / beforeunload / visibilitychange→hidden** 三条路径上自动补写（注册幂等）。
- `saveStateSync` 同时作废挂起的旧快照，避免旧数据反向覆盖新数据。

**回归**：单测 `src/services/fileService.save.test.ts`（6 条）——
防抖期不落盘（说明根因）、flush 立即落盘、**pagehide / beforeunload 实际触发补写**、无挂起时零写入、旧快照被作废。
E2E `03-files.spec.ts`：去掉原先为规避此缺陷而写的 `waitForTimeout(2000)`，改为**立即刷新**。

## ✅ L-2 导出入口隐蔽、命令面板无入口

**根因**：`file.saveAs` 未注册进命令目录（`commandCatalog.ts`），只能从编辑器工具栏「更多」进入；
且内置《使用文档》声明了 `Ctrl+Shift+S`，但该快捷键**从未绑定**。

**修复**：
- `commandCatalog.ts`：新增 `file.saveAs`（`另存为` / `Save As` / icon `download` / `Ctrl+Shift+S`）。
- 逐层打通真实动作：`EditorCommandBridge.saveAs` → `EditorLayout.openSaveAs()` →
  `CodeMirrorEditorHandle.openSaveAs()` / `TiptapEditorHandle.openSaveAs()`（各自打开内部 SaveAs 弹层）。
- `auroraActions.ts`：`'file.saveAs': runInEditor(() => cmdBridge.current.saveAs?.())`。
- `useKeyboardShortcuts` + `AuroraShell`：绑定 **Ctrl+Shift+S / ⌘⇧S**（阻止浏览器默认「网页另存为」）。

**回归**：单测 `commandWiring.test.tsx`（目录含 `file.saveAs`、快捷键解析为 `['Ctrl','Shift','S']`）；
E2E `04-io.spec.ts` 新增 —— 命令面板与 Ctrl+Shift+S 两条路径都必须打开「另存为」弹层。

## ✅ L-3 全局搜索的 Escape 仅在输入框聚焦时生效

**根因**：Escape 走容器上的 React `onKeyDown`，**只有事件目标落在浮层内才响应**；
而输入框自动聚焦是 `setTimeout(..., 50)` 延迟执行的 —— 这 50ms 窗口内按 Escape 会穿透到编辑器。

**修复**（`features/search/GlobalSearch.tsx`）：
- Escape 提升为 **window 级** `keydown` 监听（`isOpen` 期间注册，卸载时移除）。
- 从容器 React `onKeyDown` 中移除 Escape 分支，避免双触发。

**回归**：E2E `08-longtail.spec.ts` —— 打开浮层后**刻意不点输入框**、直接按 Escape，
必须能关闭（守的就是那 50ms 自动聚焦竞态窗口）。
