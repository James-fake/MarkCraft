# Markcraft 重新设计 · DesignBrief（欢迎/启动页 + 日记面板）

> 范围：用户拍板 = **欢迎/启动页 + 日记面板**，深度 = **布局范式重构**（推翻当前结构、做新信息架构），美学方向 = **先竞品调研再定**。
> 本 Brief 只出方向，不写代码。用户拍板方向后，进入"逐页 wireframe → 实施"，且实施须过 §18 §12 入站闸门。

## 0. 前提与硬约束

### 0.1 遵守 §18 桌面原生基线（不可破）
- 桌面原生定义、键盘优先、语义色单来源（`--mc-success/-warning/-danger/-info` + `-soft/-text`）、4-6px 圆角、发丝分隔（1px `border-subtle`）、hover 实色、无 FAB/无汉堡、reduced-motion、去玻璃、危险动作右置分隔、无假 affordance、单入口、分类色单来源。
- 硬禁令（§11）：紫辉光 / 渐变填充 / 毛玻璃 / 胶囊滥用 / 卡片 hover 上浮 / emoji 控件 / 过圆角 / 纯黑背景 / 过饱和 / 超大留白——一律禁止。
- **`--mc-accent: #7C8CFF` 品牌主色保留**（刻意品牌色，不禁用）；仅禁"品牌色之外的紫"。

### 0.2 复用真实数据/逻辑（不重建数据层 · 换芯铁律）
- 欢迎页：`recentFilesManager`（`getRecentFiles/subscribeRecentFiles/togglePinFile`，localStorage 持久化：fileId/fileName/lastOpened/isPinned）+ `findNode(rootFolder,id)` 校验存在。
- 日记页：`features/diary/diaryUtils`（`DAILY_PROMPTS/countWords/extractTags/makeExcerpt`）+ 现有 `DiaryWheel` 心情轮 + `MOOD_SEMANTIC_COLOR{pos:--mc-success, neg:--mc-danger, mix:--mc-warning}` + 真实日记文档（按日期命名）。
- 图标：`src/aurora/icons.tsx`（172 图标，禁 emoji）。

### 0.3 推翻的当前结构
- **欢迎页（现 `WelcomePanel`）**：紧凑 brand-bar 头部 + 左「最近文档(RecentDocs)+快速开始卡」右「成长概览」两栏静态页。→ 全部方向推翻为"启动/导航/工作台"范式。
- **日记面板（现 `DiaryPanel`）**：单屏混排（顶部日期标题 + 中部书写 + 底栏 心情/打开/删除 + 心情轮 + 回顾分布区），写作/心情/回顾堆叠一屏。→ 全部方向拆为"导航 + 书写 + 检视"分离范式。

## 2. 欢迎/启动页 — 三个新方向（2026-08-30 重做）

> 背景：首轮 A/B/C 全被否。B(仪表台)/C(导航台) 被指"一眼企业后台 / B 端控制台"（统计卡+图表+密集表格语言）；A(Commander) 被指"空、怪、没人情味"。用户要求拉开差异化、多汲取创意（非仅竞品），落在**个人·平静·文学·手作**轴。创意参考：iA Writer / Calmly Writer（首页即书写面+闪烁光标）、Bear（标签温暖单列表）、Craft（文档如藏品陈列）、Things 3（安静单栏·今天为中心）、Day One（私人时间线）。三条新方向均**非企业控制台**、互不相同、且过 §18 闸门。

### 方向 W1 · 信笺 / The Desk（首页即书写面）
- **IA**：顶部极简 brand-bar；左侧极简「最近」边栏（分类色点+名称+相对时间，≤4 行）；主区**一张空白稿纸**——轻问候 + 大号「写点什么？」+ 闪烁光标（⌘N 新建 · 自动保存 · 本地优先）。无统计、无图表、无常驻工具栏。
- **推翻**：现两栏静态页 → 打开 App 第一件事是"写"，不是"看面板"。
- **§18 符合**：最高信息克制、单入口(写)、无假 affordance、发丝分隔、圆角 4-8、唯一强调用 `--mc-accent` 光标。
- **风险**：无近期文档时显空（用"新建手稿"占位引导）。

### 方向 W2 · 文库 / The Shelf（手稿墙）
- **IA**：左窄标签栏（Bear 式：全部/产品/日记/读书/灵感，分类色点）；主区**手稿网格**——每片 = 封面（顶部分类色条 + 标题 + 最近编辑 + 字数/连续天数）；「+ 新建手稿」为单条 accent 文字按钮。
- **推翻**：现"成长概览"装饰块 → 文档作为藏品陈列，是**作品集**不是 KPI。
- **§18 符合**：真实分类色单来源(`categoricalColors.ts`)、发丝分隔、圆角 8 封面、无 hover 上浮(用实色描边表选中)。
- **风险**：文档多需虚拟滚动；封面默认文字封面(不用真实首图，防重)。

### 方向 W3 · 续写 / The Continuum（今日单焦点流）
- **IA**：顶部安静问候(晚上好·日期)；中央**唯一焦点大卡**"继续写《xxx》"(标题+一行预览+闪烁光标"接着写…")；下方一条克制「最近」纯文本列表(≤4 行)；底部一句「今日一句」写作 nudges(斜体 tertiary)。
- **推翻**：现两栏静态页 → 以"今天"为引力中心，单栏大留白，像 Things 的 Today 视图写作版。
- **§18 符合**：单栏、低密度、焦点卡用 `--mc-accent` 描边而非填充、发丝分隔、无图表。
- **风险**：若无"继续"型文档，焦点卡回退到"新建 / 今日一句"。

> **三方向对比**
> | 维度 | W1 信笺 | W2 文库 | W3 续写 |
> |------|--------|--------|--------|
> | 首页第一动作 | 写 | 浏览/选 | 继续写 |
> | 信息密度 | 最低(空灵) | 中(网格) | 低(单焦点) |
> | 私人感 | 最强 | 强(藏品) | 强(以你为中心) |
> | 企业控制台味 | 无 | 无(作品集) | 无 |
> | 最适合 | 纯写作者 | 多文档管理者 | 续写型用户 |

### 颠覆备选（用户要求更差异化 · 跨行业 · 可颠覆 · 2026-08-30 二次重做）
- 用户反馈：W1/W2/W3 仍"不够差异化"，明确要求**不限于写作类参考、任何行业内容都可、要颠覆**。故从非写作域借范式，结构级颠覆，仍守 §18 视觉纪律（token/发丝/无辉光/无紫）。
- **X1 · 杂志封面 / The Issue（出版·编辑域）**：首页=你**自出版的月刊**——报头「本期·二〇二六年八月」+ 卷期；主区一篇 featured「封面文章」(你最近/最重要文档，大标题+署名"文/HJN"+导语)；下方「目录」把其余文档当 TOC 条目(带页码趣味)；底部「卷首语」写作 nudges。颠覆点：个人笔记=你给自己发行的刊物，文学感、非控制台。
- **X2 · 星图 / The Constellation（空间·知识图谱域）**：首页=可交互的**发丝节点图**——每篇文档一个节点，细 1px 线相连(扁平无辉光)，「今天」节点 accent 高亮、可拖动排布。颠覆点：用空间记忆取代列表/网格，像私人宇宙。
- **X3 · 一镜到底连续稿 / The Continuum（lifelog·单流域）**：**废除"文件"概念**，全 app 是**一册不间断手稿**；首页即稿顶——日期+今日首行光标，其下你的文字按时间无缝续写，仅以淡日期标记分段，无侧栏/无库/无卡。颠覆点：彻底消灭文件/列表/库隐喻。
- 待用户从 X1/X2/X3 选（或继续颠覆）。

### 最终拍板（2026-08-31）：L1 Launchpad 主屏 v2（欢迎页定稿）
- **决策路径**：A/B/C(被指"一眼企业后台/B 端控制台"，统计卡+图表+密集表格语言) → W1/W2/W3(个人·平静·文学轴，仍"不够差异化") → X1/X2/X3(跨行业颠覆，仍不满意) → L1/L2/L3(用户要求"彻底脱离写作/文档/笔记")。用户从 L1/L2/L3 中选 **L1 Launchpad 主屏**，并给 4 点精修反馈：① 左上加法线 logo + 放大标题做视觉锚点；② 加按时段问候 + 使用天数（人情味）；③ 打破工整（左大右小非对称）；④ 搜索并进网格。精修版 **L1 v2 获认可定稿**。
- **最终 IA（L1 v2）**：
  - 顶部 brand-row：左上 logo(圆角方块 + 蓝紫 M 标) + 「MarkCraft」22px 标题（视觉锚点）；其下行动态问候「晚上好，HJN · 这是你使用 MarkCraft 的第 N 天」(N=接首次启动日，线框暂占位 128)。
  - 主区**非对称网格**：左侧一个竖长大卡 = **编辑器**（你上次停留的模块，accent 描边 + 上次编辑文档名）；右侧 **2×3 小 tile 网格** = 日记 / 知识库 / 白板 / 博客 / 设置 / 搜索（6 入口，每 tile = 线性图标 + 模块名，**无内部计数、无假状态**）。
  - 图标：lucide 式线性描边（`src/aurora/icons.tsx`，禁 emoji）；仅「上次停留」模块(编辑器大卡)加克制 accent 圆点/描边。
  - 首页**完全不谈写作/文档/笔记**——是中性启动器，进去才是各模块。
- **§18 符合**：真实 token、发丝分隔、4-12px 圆角、无玻璃/无紫辉光、唯一 accent 仅作大卡描边与 logo；过 §12 闸门。
- **实施目标文件**：`src/aurora/panels/welcome/WelcomePanel.tsx` + `welcome.css`（推翻现两栏静态页 P2.1）。
- **✅ 已实施（2026-08-31）**：重写 `WelcomePanel.tsx`（掀掉 `useDashboardData` KPI+365 热力图整段、删底部写作模板条）+ `welcome.css`（L1 v2 新 BEM 类，扁平暗色/发丝/唯一 accent）；死组件 `QuickStartCard.tsx` 退役；人情味问候接真实数据（使用天数=localStorage 首启日、连续天数=recentFiles 活动派生）；左大卡取 `getRecentFiles()[0]`、tile 走 `handleNav`/搜索走命令面板。烟雾测试 `WelcomePanel.smoke.test.tsx` 4 用例全绿，tsc=0。待 dev 5174 截图肉眼验收。

## 3. 日记面板 — 已拍板方向 B（时间线流）

> **已拍板（2026-08-31 定稿）**：方向 B 时间线流，最终微调为——**左列整屏编辑器（日期头水平紧凑条 + 合并块：格式栏+真实 TiptapEditor）、右栏常驻 mini 月历（hover 弹出当日日记浮窗、点击载入那天） + 那年今日 + 每日一问**。以下保留三方向原文供追溯，A/C 为落选方案。

### 方向 A · Day One 式三栏（日期导航 + 书写 + 检视）
- **IA**：
  - 左栏 **日期导航**：月历(格高亮写过/空缺, 蓝=1/橙=2/红=今天) + 那年今日入口 + 连击天数；
  - 中栏 **书写面**：大日期标题(如"2026年8月30日 周日") +  distraction-free markdown 编辑器（复用现有编辑器内核）+ 当日可有多条 entry 纵向排布；
  - 右栏 **检视/inspector**：心情(复用 DiaryWheel, 语义色) / 标签(extractTags) / 自动元数据(字数 countWords·相对时间) / 模板一键载入(DAILY_PROMPTS) / 当日 entry 列表。
  - 底部：**格式 / 附件+元数据 / 标签+模板** 三菜单（Icon.*，非 emoji）。
- **交互**：左栏选日期→中栏载入该日；右栏编辑元数据实时写回；⌘D 开今日(Meridian 范式)。
- **推翻**：现单屏混排 → 导航/书写/检视三区分离，最贴近专业日记 App。
- **§18 符合**：桌面原生三栏、键盘优先(⌘D/⌘K)、语义色心情、Icon.* 无 emoji、发丝分隔。
- **风险**：三栏在窄屏拥挤；右栏 inspector 信息层级需克制防"网页味"。

### 方向 B · 时间线流（Logseq / Obsidian daily-notes）
- **IA**：左 mini 月历(跳转)；主区 **竖向时间线**：每天 = 一个日期节点(大日期标题 + 当日 entry 流)，倒序；点节点展开/编辑，或聚焦进书写面；右栏可选(当年统计/那年今日)。
- **交互**：滚动即浏览日志；写新日记 = 在时间线顶部"今天"节点内联编辑；历史节点点击展开全文。
- **推翻**：现"单文档+心情轮" → 日志即流，每天是流中的一个条目。
- **§18 符合**：高密度流、键盘滚动、无卡片堆叠(用发丝分隔而非卡片)。
- **风险**：长日志滚动性能；与现有"每日记一篇"数据模型需对齐(可一天多 entry)。

> **✅ 已实施（2026-08-31）**：推翻原三栏（左每日一问+环形图 / 中 3D 滚轮+全年热力图+本月复盘 / 右 KPI 条+编辑）为两栏时间线流。
> - `DiaryPanel.tsx` 重写：左列 `.dv2-editor-col`（水平日期头 + 合并块 `.dv2-editor-block`=DiaryFormatToolbar+TiptapEditor+底部动作条；空态「写这篇日记」）；右列 `.dv2-side-col`=DiaryMiniCalendar(常驻月历, hover→`.dv2-popover-wrap` 浮窗卡在「那年今日」上方、移开 0.26s 平滑回弹) + 那年今日(复用 `onThisDay`) + 每日一问(DAILY_PROMPTS)。

### 方向 C · 双栏日记（SimpleJournalQt / Meridian）
- **IA**：左栏 **日记列表**：按月分组(日期 + excerpt 摘要 + 心情点)，致密；右栏 **合并 MD 浏览/编辑**：大日期标题 + 编辑器；View/Edit 切换(或实时预览)。
- **交互**：左选日记→右载该日；最低学习成本，像笔记 App。
- **推翻**：现单屏 → 列表+编辑分离，最接近"笔记应用"心智。
- **§18 符合**：双栏原生、高密度列表、语义色心情点。
- **风险**：与方向 A 比少了"多视图/那年今日"专业感；偏朴素。

> **三方向对比**
> | 维度 | A Day One 三栏 | B 时间线流 | C 双栏日记 |
> |------|--------------|-----------|-----------|
> | 专业度 | 最高(多视图/那年今日/模板) | 高(流) | 中(朴素) |
> | 信息密度 | 高(三栏) | 高(流) | 中 |
> | 与现有数据对齐 | 需支持多 entry/日 | 需支持多 entry/日 | 单 entry/日即可 |
> | 实现量 | 最大(三栏+inspector) | 中(流+历) | 最小(列表+编辑) |
> | 学习成本 | 中 | 低(滚) | 最低 |
