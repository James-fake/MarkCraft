# MarkCraft 隐私政策（匿名使用统计）

> 生效版本：1.0.0
> 本文说明 MarkCraft 内置的「匿名体验改善计划」会收集什么、不会收集什么，以及你如何掌控它。
> 本政策仅适用于应用内的匿名使用统计；你的笔记内容始终由你自己掌握。

## 1. 核心原则

MarkCraft 是**本地优先（local-first）**的桌面笔记应用，你的所有笔记都存储在你自己的设备上。
内置的使用统计**默认关闭（opt-in）**：在你明确同意之前，应用**不会向任何服务器发送任何数据**。

## 2. 我们只收集匿名、聚合的数据

在你开启「体验改善计划」后，我们仅收集以下**不含任何个人身份信息**的数据：

| 类别 | 字段 | 说明 |
| --- | --- | --- |
| 匿名标识 | 安装 ID | 本地随机生成的 UUID，仅用于去重同一安装实例，与任何个人信息无关 |
| 环境基线 | 应用版本、操作系统、界面语言 | 用于区分数据归属与兼容性 |
| 使用统计 | 功能使用次数 | 如编辑器、图谱、博客、白板、知识库等功能被使用的计数 |
| 使用统计 | 功能停留时长 | 你在各功能面板停留的毫秒数（用于判断哪些功能最受欢迎 / 最被冷落） |
| 健康度 | 崩溃信息 | 仅记录未捕获错误的**类名**（截断），**绝不**记录错误消息或堆栈中的任何内容 |
| 活跃度 | 每日心跳 | 用于推断「安装多久后流失」，比硬抓卸载事件更可靠 |

## 3. 我们绝不收集

- ❌ 你的**笔记正文、标题、文件名、文件路径**；
- ❌ 你的**个人信息**（姓名、邮箱、账号等）——除非你主动在「用户设置」中填写且该功能与统计无关；
- ❌ 精确的 **IP 地址 / 地理位置**；
- ❌ 任何能反推出「你写了什么」的内容。

笔记内容永远不会离开你的设备，也不会进入统计管线。

## 4. 数据如何发送

- 仅在你**授权后**，且运维方配置了上报端点，才会发送；
- 通过 **HTTPS** 发送到你所部署的**隐私友好分析服务**（如 Umami、Plausible、PostHog 等的自定义事件接口）；
- 批量、防抖发送，失败静默丢弃，**绝不影响应用正常使用**；
- 应用关闭时用 `sendBeacon` 尽力送达最后一批。

## 5. 你的控制权

- **默认关闭**：首次运行会弹出询问，勾选「我同意」才加入；不勾选则保持隐私。
- **随时可关**：「设置 → 隐私」中可一键关闭；关闭后**立即停止发送**，且缓冲中未发出的数据会被清空。
- **本地数据清除**：安装 ID 仅存于本机 `localStorage`，清除应用数据即可一并移除。

## 6. 数据保留与删除

所有上报数据均为匿名、聚合形态，用于产品改进。是否长期留存、留存多久，由你所部署的分析服务端配置决定。MarkCraft 客户端本身不保留任何已发送事件的副本。

## 7. 第三方服务

MarkCraft 本身**不强加任何特定的分析服务商**。上报端点由部署方通过构建期环境变量配置，数据流向你信任的隐私友好分析服务。请在启用前确认该服务商的隐私条款。

## 8. 联系我们

如对本政策有疑问，可通过应用内「关于」页面的渠道与我们联系。
