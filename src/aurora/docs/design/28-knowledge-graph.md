# 28 · 知识图谱（Knowledge Graph）规范

> 对应 `panels/kb/GraphPanel.tsx` + `styles/panels/graph.css`。数据全部 mock（`RAW_NODES`/`RAW_EDGES`）。**本面板为演示中交互最完整的模块**，以下为其真实实现清单。

## 1. 面包屑与状态栏

- `breadcrumbs`：`['双链图谱']`（单级，无"知识库"父级）。
- 状态栏左：笔记/标签/文件夹/连线 计数；右：模式 / 布局 / 缩放%。

## 2. 导航面板（左侧栏 · hover 展开）

鼠标靠到画布左缘（**7px 隐形感应条**，对齐编辑器 v7 范式）停留约 220ms 即滑入浮层，移出约 180ms 后收起；浮层头部提供**图钉**（钉成常驻栏）与「收起」按钮。浮层绝对定位覆盖画布之上，不挤压画布重排。面板名「图谱导航」。高频操作（搜索 / 节点类型）在顶部筛选条，左侧栏定位为导航 + 视图配置。

> **使用优化⑤（2026-09-10）· 重排与瘦身**：① 顶栏「着色」按钮删除（分组着色配置统一收敛到左栏）；② 左栏按使用习惯重排为四区——**视图控制**（图谱模式/布局方式）→ **筛选与显示**（标签筛选/连接强度/显示开关组）→ **着色**（着色分组导航/分组着色·默认折叠）→ **信息**（链接健康），区间以发丝 divider 分隔，末尾「重置视图」；③ 左栏图例区块删除（图例职责由底部状态栏承担）；④ 分组着色默认折叠（grp-body 仅 CSS 隐藏、始终在 DOM，测试兼容）；⑤ 分组色板圆圈行与「添加分组」按钮居中。

> **使用优化⑦（2026-09-11）· 触发条统一 + 改名**：① 左栏触发由 18px 满高「导航」竖条按钮（点击展开、flex 挤压画布重排）整体更换为编辑器 v7 权威范式——7px 隐形感应条 + hover-intent（220ms/180ms）+ overlay 浮层（256px absolute 不挤压）+ 图钉常驻，与编辑器/白板边缘召唤逐字同款（至此全站 5 处边缘召唤同源）；② 功能名「知识图谱」更名「**双链图谱**」（侧边栏/菜单栏/命令面板三入口同步，命令面板 keywords 保留旧名兜底搜索）。

## 3. 视图控制（右下面板）

缩小(`minus`) / 缩放% (点击→100%) / 放大(`plus`) / 分隔 / 适应(`frame`) / 聚焦(`target` `focusCenter`) / 全屏(`maximize` `toggleFullscreen`) / 分隔 / 导出(`download`)。导出下拉：PNG / SVG / JSON。

## 4. 节点信息卡

标题 + 类型徽章（current/file/tag/folder/孤立笔记/笔记）+ `filePath` + `tags` + 统计网格（入链/出链/字数/修改 `relTime(modifiedAt)`）+ 操作按钮：打开笔记(`arrowR`)/在图谱中聚焦(本地)/查看反向链接(backlinks)/添加标签(`tag`)。⚠️ "添加标签"为 `toast` 桩。

## 5. 底部状态栏

居中胶囊：统计 + 图例（布局 Segmented 已去重删除，布局切换在左栏「布局方式」）。

## 6. 迷你地图

⚠️ 已移除（2026-09-02）：原右上角迷你地图（导航总览，`onMiniMapClick` 点击跳转）已按需求删除。平移/缩放改由画布拖拽、滚轮缩放（光标居中）与右下视图控制条的「适应视图 / 聚焦当前笔记」承担。

## 7. 节点 / 边数据模型

- 节点类型：`file`(14) / `tag`(7) / `folder`(2，**合成数据，真实项目无 folder 节点**) / `current` 标记在 n1；`orphan` 为派生（file 且 deg=0，当前无实际孤立节点）。
- 边类型：`wiki` / `embed` / `tag` / `folder`。
- 布局：force 为真实力模拟但**不自动运行**（初始静态环形，交互时才 reheat）；concentric/tree/grid 为 BFS 定位。

## 8. 交互桩 / 未实现

- 力模拟默认不自动运行（设计如此）。
- 右键菜单"展开邻居" → `toast` 桩；信息卡"添加标签" → `toast` 桩。
- 文件双击 → `nav('editor')` + toast；标签双击 → 加入 `selectedTags`。
- 无"当前"复选框（为单节点 flag）；无"标签关联"开关（仅文件夹关联）；无真 zoom-to-fit 边界（适应仅重置 scale=1）；无键盘快捷键；无按边/正文搜索；无社区聚类；无持久化/后端；folder 节点为合成。
